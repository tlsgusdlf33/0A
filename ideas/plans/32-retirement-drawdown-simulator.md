# 32. 연금 수령·인출 전략 시뮬레이터

## 최종 목표
- **목표 은퇴 나이에 "자금이 바닥날 확률 10% 이하"가 되도록 하는 월 저축액을 산출**하고 매년 갱신
- 기본 전략 대비 최적 수령·인출 전략의 **평생 세후 수령액 차이**를 숫자로 제시
- 입력은 연 1회 30분 이내, 나머지(25번 잔고 반영·제도 수치 갱신 알림)는 자동

## MVP 범위
- 입력: 국민연금 예상액, 퇴직연금·연금저축·IRP 잔액, 일반 투자자산(25번), 은퇴 후 목표 생활비
- 결정론적 연도별 현금흐름 + 몬테카를로 시뮬레이션
- 비교 전략 3~5개와 결과 리포트(그래프 포함)

## 기술 구조
- 언어: Python (numpy, pandas), 리포트는 정적 HTML 그래프
- **제도·세법 수치는 연도별 설정 파일**(출처 메모 포함), 제도 개편 시 갱신:
  - 국민연금: 출생연도별 수령 개시 연령, 조기수령 감액(연 6%, 최대 5년), 연기 가산(연 7.2%, 최대 5년), 2025년 연금개혁에 따른 보험료율·소득대체율 변화
  - 사적연금: 분리과세 기준(연 1,500만 원) 초과 시 과세 방식 선택, 나이별 연금소득세율, 퇴직금을 연금으로 받을 때 퇴직소득세 감면
  - 건강보험: 피부양자 소득 기준, 지역가입자 보험료에 반영되는 소득 범위
- 시장 시나리오: 25번 포트폴리오 자산군의 과거 수익률 부트스트랩(수천 경로) + 물가상승률
- 전략 탐색: 국민연금 개시 연령(조기~연기) × 인출 순서(일반계좌 먼저 / 연금 먼저 / 분리과세 한도까지 연금 + 나머지 일반계좌) × 인출률
- 연동: 25번(포트폴리오·잔고), 12번(연금 세액공제 한도 활용), 31번 kit(config 모듈)
- 비용: 0원

## 단계별 절차
| 단계 | 할 일 | 완료 기준 |
|---|---|---|
| 0. 자료 모으기 | 통합연금포털 전체 조회, 국민연금 예상 수령액, 연금계좌별 잔액·세액공제받은 납입액 구분 | 입력 파일 1개 |
| 1. 제도 설정 파일 | 위 수치들을 출처와 함께 YAML로 | 설정 파일만 바꾸면 계산이 바뀜 |
| 2. 연도별 현금흐름 | 결정론적(고정 수익률) 모델: 납입 → 은퇴 → 인출 → 잔액 | 손계산 사례 3개와 일치 |
| 3. 세금·건보료 모듈 | 연금소득세, 분리과세 선택, 퇴직소득세 감면, 건보료 추정 | 공식 계산기·안내 예시와 비교해 오차 확인 |
| 4. 몬테카를로 | 수익률·물가 시나리오 수천 개, 고갈 확률·세후 총수령·남는 자산 분포 | 실행 1분 이내 |
| 5. 전략 비교 | 개시 연령 × 인출 순서 × 인출률 탐색, 상위 전략 3개 리포트 | 기본 전략 대비 차이 표시 |
| 6. 지금 할 일 역산 | 고갈 확률 10% 이하가 되는 월 저축액, 연금계좌 세액공제 한도 활용(12번), 자산배분 조정 제안(25번) | "이번 달부터 할 일" 3줄 |
| 7. 자동 갱신 | 25번 잔고 월 1회 반영, 매년 1월 제도 수치 점검 알림, 결과 변화가 크면 알림 | 연 1회 30분 입력으로 유지 |
| 8. (선택) 확장 | 주택연금 시나리오, 배우자 합산 시뮬레이션 | 시나리오 추가 |

## 법·정책 주의사항
- 본인용 계획 도구: 결과를 다른 사람에게 상품 추천으로 제공하면 투자자문 규제 대상
- 연금·세법·건보료 제도는 자주 바뀜: 결과는 추정치이며 실제 수령·과세는 공단·국세청 기준
- 금융 데이터는 로컬·비공개 보관

## 리스크와 대응
- 장기 가정(수익률·물가)에 결과가 민감 → 가정을 바꾼 민감도 표를 항상 함께 표시
- 제도 개편 → 설정 파일 갱신 체크리스트, 갱신 전 결과에 "기준 연도" 표시
- 과도한 정밀도 착시 → 결과를 구간(확률 분포)으로 보여주고 단일 숫자 강조 지양
