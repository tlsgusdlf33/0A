# 53. 동화 → 부모 목소리 낭독 오디오북 + 그림책 인쇄

> **A8 보완 제안 (2026-10-22)**: 사용자 개인 세션 A8(5살 아이 동화, 매주 금요일 생성)의 결과물을 입력으로 씁니다. A8 레포에 `audiobook/`·`picturebook/` 모듈로 두는 것이 자연스럽습니다. 실물 인쇄는 G6(39번 판매 인프라)에 흡수된 30번 주문형 인쇄 연동을 재사용합니다. 개인 세션이라 사용자가 지시할 때만 A8 세션에 전달합니다.

## 최종 목표
- A8이 동화를 만드는 금요일마다 **부모 목소리 낭독 오디오가 자동으로 함께 생성** (사람 손 0분)
- 한 달에 한 번, 그 달 동화 4편을 묶은 **그림책 PDF 자동 완성** → 원하면 버튼 한 번으로 실물 책 주문
- 아이가 잠들기 전 폰·스피커로 바로 들을 수 있게 재생 화면 제공
- (확장) 맞춤 그림책을 30번 판매 사이트 상품으로 판매할지 6개월 뒤 결정

## MVP 범위
- 목소리 등록: 부모가 안내 문장 5~10분 녹음 → 음성 모델 생성 (본인 목소리, 본인 동의)
- 낭독: 동화 텍스트 → 문장 단위 음성 합성, 등장인물 대사 억양 구분(선택), 배경 음악 옵션
- 오디오 파일: MP3 + 장면 표시, 앱 재생 화면(잠자기 타이머)
- 삽화: 장면별 그림 4~8장, 같은 캐릭터 모습 유지(캐릭터 설정 고정)
- 그림책: 표지·본문·마지막 장(아이 이름·날짜) PDF, 인쇄 규격(정사각 20cm 등)
- 인쇄 주문: 30번 주문형 인쇄 연동으로 PDF 전달 → 결제 → 배송

## 기술 구조
- 입력: A8이 생성·저장하는 동화(텍스트·제목·등장인물)
- 음성: 목소리 복제를 지원하는 음성 합성 API (본인 녹음 기반, 약관상 본인 목소리 사용 허용 여부 0단계에서 확인), 음성 모델 ID만 보관하고 원본 녹음은 사용자 저장소에만
- 삽화: 이미지 생성 API + 캐릭터 설정 프롬프트 고정, 부적절 이미지 필터
- 편집: PDF 레이아웃 자동 생성(글 위치·글꼴 크기 아동용)
- 앱: 안드로이드 APK (Termux 없이, 앱 내 업데이트) 재생 화면 + PC에서 그림책 미리보기·주문
- 실행: A8 예약 작업(금요일) 직후 자동 실행

## 단계별 절차
| 단계 | 할 일 | 완료 기준 |
|---|---|---|
| 0. 서비스 선택 | 목소리 복제 음성 API 2곳 비교 (한국어 품질, 본인 목소리 사용 약관, 데이터 보관 정책, 비용) | 서비스 결정 |
| 1. 목소리 등록 | 녹음 안내 문장 세트, 녹음 품질 검사(잡음·음량) | 음성 모델 생성 |
| 2. 낭독 생성 | 동화 1편 → MP3, 문장 끊김·발음 오류 검사 | 가족이 들어서 자연스럽다고 판단 |
| 3. 자동 연결 | A8 금요일 작업 직후 오디오 자동 생성·알림 | 2주 연속 자동 생성 |
| 4. 재생 화면 | 목록·재생·잠자기 타이머 | 폰에서 바로 재생 |
| 5. 삽화·그림책 | 장면 삽화, 캐릭터 일관성, 월간 그림책 PDF | 4편 묶음 PDF 완성 |
| 6. 인쇄 주문 | 30번 주문형 인쇄 연동, 미리보기 → 주문 | 실물 책 1권 수령 |
| 7. 판매 검토 | 맞춤 그림책 상품화(30번 판매 사이트) 수요·비용 검토 | 판매 여부 결정 |

## 법·정책 주의사항
- 목소리 복제는 **본인 목소리만**, 녹음자 본인 동의 기록. 다른 사람 목소리 사용 기능은 만들지 않음
- 음성 모델·녹음은 가족 외 공유 금지, 서비스 탈퇴 시 삭제 요청 절차
- 아이 이름·사진 등 아동 개인정보는 최소 수집, 외부 공개 금지
- 판매로 확장할 경우 이미지 생성물 상업 이용 약관, 전자상거래 고지(39번 엔진) 확인

## 리스크와 대응
- 합성 음성 품질이 어색함 → 녹음 분량을 늘리거나, 특정 문장은 직접 녹음으로 교체하는 기능
- 삽화 캐릭터가 회차마다 달라짐 → 캐릭터 기준 이미지·설정 고정, 이상 이미지는 재생성
- API 비용 → 월 4편 기준 비용 상한 설정, 그림책은 월 1회만 생성
