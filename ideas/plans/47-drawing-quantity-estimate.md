# 47. 2D 도면 → 물량·중량 산출 & 견적서 자동화

> **A6 보완 제안 (2026-10-19)**: 사용자 개인 세션 A6(2D 도면 → 3D 모델링·분석 자동화, Windows .exe)에 붙이는 기능입니다. A6이 만든 3D 모델을 입력으로 쓰므로 A6 레포에서 개발하는 것이 자연스럽습니다. 개인 세션이라 사용자가 지시할 때만 A6 세션에 전달합니다. 46·51번과 함께 "건설기계 실무 도구" 묶음으로도 연결 가능합니다.

## 최종 목표
- 도면 1세트 물량 산출 시간 **반나절 → 20분 이하** (자동 산출 + 검수)
- 손 계산 대비 물량 오차 **5% 이내** (철골·판금·배관 등 형상 단순 분야)
- 12개월 안에 유료 고객(소규모 제작·설비·철골 업체) 20곳 또는 건별 견적 200건
- 44번(나라장터 용역 매칭)에서 엔지니어링 용역 실적으로 활용

## MVP 범위
- 입력: A6의 3D 모델(또는 A6 내부 부재 데이터), 재질 선택(강재·스테인리스·알루미늄 등)
- 산출: 부재별 수량·길이·면적·체적·중량, 절단 길이 목록, 용접 길이(근사), 도장 면적
- 견적: 단가표(재료 kg당·가공비·도장 m²당·운반) 적용 → 견적서·자재 발주 목록 엑셀
- 변경 비교: 도면 개정 전후 물량 차이표

## 기술 구조
- A6 .exe에 "물량·견적" 메뉴 추가 (Python 계열이면 같은 언어로 모듈화)
- 부재 인식: A6 모델의 솔리드/부재 정보 → 형강 규격(H형강·ㄱ형강·각관 등) 매칭 표
- 재질 밀도·형강 단위중량 표: KS 규격 단위중량 값 내장
- 단가표: 사용자가 엑셀로 관리, 앱이 읽어 적용 (업체별 단가 저장)
- 출력: openpyxl 엑셀, PDF 견적서(회사 정보·유효기간·부가세)
- 폰 연동(선택): 견적서 PDF를 폰으로 보내 현장에서 확인

## 단계별 절차
| 단계 | 할 일 | 완료 기준 |
|---|---|---|
| 0. A6 구조 파악 | A6 레포의 모델 데이터 구조·출력 형식 확인, 부재 정보 접근 방법 결정 | 부재 목록 추출 가능 확인 |
| 1. 규격·밀도 표 | 형강 규격·단위중량, 재질 밀도 표 내장 | 대표 규격 100종 |
| 2. 물량 산출 | 부재별 길이·면적·체적·중량, 절단 목록 | 실제 도면 3장 손 계산 대비 오차 5% 이내 |
| 3. 견적서 | 단가표 적용, 견적서·발주 목록 엑셀·PDF | 업체 양식과 비교해 바로 발송 가능 |
| 4. 변경 비교 | 개정 전후 물량 차이표 | 개정 도면 2쌍으로 검증 |
| 5. 시범 고객 | 지인·주변 제작 업체 2곳 무료 사용, 피드백 | 실제 견적 10건 작성 |
| 6. 판매 | 건별 과금(견적 1건) 또는 월 구독, 설치형 라이선스 | 유료 고객 5곳 |
| 7. 확장 | 배관·덕트 물량, 볼트·부속 자동 집계 | 분야 2개 추가 |

## 법·정책 주의사항
- 고객 도면은 영업비밀 → 로컬 처리 기본, 서버 업로드 시 동의·암호화·삭제 정책
- KS 규격 수치 사용은 가능하나 규격 문서 원문 재배포 금지
- 견적은 참고용이며 최종 금액 책임은 사용자에게 있음을 명시

## 리스크와 대응
- 도면 인식 오류 → 부재별 검수 화면에서 규격·수량 수정 가능, 수정 이력이 다음 인식에 반영
- 업종마다 단가 구조가 다름 → 단가표를 엑셀로 열어 두어 자유롭게 구성
- A6 개발 방향과 충돌 → A6 세션에 전달할 때 메뉴 추가 방식(기존 기능 비침범)으로 제안
