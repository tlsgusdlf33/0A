# 87. 장비 이력 인증 리포트 (중고 매각가 향상)

> **G8 후보·63번(G5) 보완 제안 (2026-11-03)**: 52번 가동 기록·64번 정비·원가·51번 진동 추세를 모아 63번 공매·중고 매각 판매글에 첨부. G8 묶음이 구성되면 그 주 세션에서 개발. **작업 대기**

## 최종 목표
- 장비 1대 이력 리포트 PDF 1분 안에 생성
- 이력 리포트 첨부 매물의 매각가가 비첨부 대비 높게 형성되는지 검증 (목표 +5%)

## MVP 범위
- 가동 시간 추이, 정비·부품 교체 내역(영수증 근거), 진동 상태 추세, 사고·수리 이력
- 위·변조 방지: 기록 생성 시각·해시 포함, 원본 증빙 목록

## 단계별 절차
| 단계 | 할 일 | 완료 기준 |
|---|---|---|
| 0. 항목 정의 | 중고 장비 구매자가 보는 항목 조사 | 리포트 항목 확정 |
| 1. 데이터 연결 | 52·64·51번 기록 통합 | 장비 1대 데이터 통합 |
| 2. 리포트 | PDF 생성·해시 | 1분 이내 생성 |
| 3. 판매 연동 | 63번·21번 판매글 첨부 | 매각 1건 적용 |

## 주의
- 기록에 없는 이력은 "기록 없음"으로 정직하게 표시
