# 57. 소상공인 전기요금 계약전력·요금제 최적화 진단

> **연결 제안 (2026-10-24)**: 독립 프로젝트로 진행하되, 고객이 같은 10번(소상공인 리뷰 답글 SaaS, 42번 신규 개업 리드 포함) 채널로 판매하는 것을 권장합니다. 진단 리포트 결제는 G6(39번 결제 엔진)을 쓸 수 있습니다.

## 최종 목표
- 사용량 파일 업로드 후 **3분 안에** 계약전력·요금제 진단 리포트 완성
- 절감 가능 매장에서 **연간 기본요금 10% 이상 절감안** 제시 (계산 오차: 실제 고지서 대비 3% 이내)
- 12개월 안에 진단 200건, 유료 전환 60건 (진단 1건 9,900원 또는 절감액 기반 성공 수수료)
- 사장님이 들이는 시간: 한전ON에서 파일 내려받기 + 업로드 5분

## MVP 범위
- 입력: 한전ON(전력 사용량 조회)에서 내려받은 15분 또는 시간 단위 사용량 파일, 최근 고지서 정보(계약 종별·계약전력·선택요금)
- 분석: 월별 최대수요전력, 계절·시간대(경부하·중간·최대부하) 사용 패턴, 기본요금 비중
- 시뮬레이션:
  - 계약전력 하향 시 연간 기본요금 절감액과 초과 사용 위험(초과 시 추가 요금)
  - 선택요금제(I·II 등) 변경 시 연간 요금 차이
  - 사용 패턴 개선 제안(최대부하 시간대 설비 분산)
- 리포트: 현재 vs 추천안 비교표, 연간 절감액, 위험 요인, 변경 신청 방법·필요 서류 안내
- 영업: 진단 무료 요약(절감 가능 여부만) → 상세 리포트 유료

## 기술 구조
- 웹(모바일 우선): 사장님이 폰에서 파일 업로드 → 결과 화면·PDF (사용자 본인용이 아닌 고객 대상 서비스라 앱 설치 없이 웹)
- 요금 계산 엔진: 한전 전기요금표(계약 종별·전압·계절·시간대 단가, 기본요금) 데이터화, 요금 개편 시 갱신 (31번 세법·제도 수치 레지스트리 방식 참고)
- 파일 파서: 한전ON 내려받기 형식(엑셀·CSV) 처리, 결측 구간 보정
- 리포트: PDF 생성, 신청 안내 체크리스트
- 결제: 39번 결제 엔진 또는 간편결제, 진단 이력은 고객 계정에 저장

## 단계별 절차
| 단계 | 할 일 | 완료 기준 |
|---|---|---|
| 0. 요금 체계 정리 | 일반용(갑·을)·계약전력·선택요금제 규정, 계약전력 변경 조건·주기 정리 | 요금표·규정 데이터화 |
| 1. 계산 엔진 | 사용량 → 월 요금 재현 | 실제 고지서 3건과 오차 3% 이내 |
| 2. 파일 파서 | 한전ON 내려받기 형식 처리, 결측 보정 | 샘플 파일 5종 정상 처리 |
| 3. 시뮬레이션 | 계약전력 조정·요금제 변경 연간 비교, 초과 위험 계산 | 추천안별 절감액·위험 표시 |
| 4. 리포트 | 비교표·절감액·신청 안내 PDF | 사장님이 읽고 이해 가능한 한 장 요약 |
| 5. 시범 진단 | 지인 매장 5곳 무료 진단, 실제 변경 후 고지서로 검증 | 절감 실현 사례 2건 |
| 6. 판매 | 무료 요약 → 유료 상세, 10번 고객·42번 신규 개업 리드에 안내 | 유료 진단 20건 |
| 7. 확장 | 고압 사용 업종(제조·냉동창고) 지원, 계절별 재진단 알림 | 업종 확대 |

## 법·정책 주의사항
- 진단은 참고용이며 계약 변경 결정과 신청은 고객 본인 (한전 규정상 변경 조건·주기 제한 안내)
- 사용량 데이터는 영업정보 → 진단 후 원본 삭제 옵션, 동의 범위 안에서만 보관
- 성공 수수료 방식은 계약서로 산정 기준 명확화

## 리스크와 대응
- 요금 개편으로 계산이 틀림 → 요금표 버전 관리, 개편 공지 감시
- 절감 여지가 없는 매장이 많음 → 무료 요약으로 걸러 유료 진단의 만족도 확보
- 사장님이 파일 내려받기를 어려워함 → 화면 캡처형 단계별 안내, 고지서 사진만으로 하는 간이 진단 옵션
