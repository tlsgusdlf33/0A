# 83. 내 제품 리콜 자동 감지 알림

> **18번(G2) 보완 (2026-11-02 사용자 지시로 18번 세션에 전달)**: 18번 보증서·영수증 데이터의 제품 모델명 재사용.

## 최종 목표
- 등록 제품·차량의 리콜 발표를 7일 안에 100% 알림

## MVP 범위
- 리콜 공공데이터(소비자 제품 리콜, 자동차 리콜) 매일 수집
- 등록 제품 모델명·차량 정보와 매칭(모델명 표기 차이 정규화)
- 알림: 리콜 내용, 조치 방법, 신청처

## 단계별 절차
| 단계 | 할 일 | 완료 기준 |
|---|---|---|
| 0. 데이터 | 리콜 공공데이터 API 확인 | 수집 가능 |
| 1. 매칭 | 모델명 정규화·매칭 | 과거 리콜 사례 테스트 통과 |
| 2. 알림 | 해당 시 알림 | 테스트 알림 정상 |

## 주의
- 공공데이터 출처 표시, 차량 정보는 기기에만 저장
