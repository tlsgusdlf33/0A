# 56. 공공 체험·캠핑장 예약 오픈 사전 알림

> **A9 보완 제안 (2026-10-24)**: 사용자 개인 세션 A9(주말 가족 나들이 일정, '주말나들이' 앱)에 붙이는 기능입니다. A9 앱의 알림·일정 화면에 모듈로 넣는 것을 권장합니다. 개인 세션이라 사용자가 지시할 때만 A9 세션에 전달합니다. 지역 공공데이터 수집 코드는 G4(1번 사이트)와 공유할 수 있습니다.

## 최종 목표
- 아이 나이·지역·주말 조건에 맞는 공공 체험·캠핑장·휴양림 예약을 **접수 시작 전에 100% 알림** (놓친 접수 0건)
- 한 달에 2회 이상 무료·저가 공공 프로그램으로 나들이 → 나들이 비용 절감
- 사람이 들이는 시간: 알림 확인 후 예약 사이트로 바로 이동, 탐색 시간 0분

## MVP 범위
- 출처(공개 API·공개 데이터 우선):
  - 지자체 공공서비스예약(예: 서울시 공공서비스예약 정보 API) — 체험·교육·공원·문화행사
  - 국립자연휴양림·국립공원 야영장 등 공공 예약 정보 (예약 오픈 일정 공지 기준)
  - 문화 공공데이터(공연·전시·어린이 프로그램)
- 조건: 아이 나이(대상 연령), 거주지 기준 이동 거리, 주말·공휴일, 무료/유료 상한, 관심 분야(자연·과학·만들기 등)
- 알림: 새 프로그램 감지 즉시, 접수 시작 전날 저녁, 1시간 전, 마감 임박
- A9 연동: 후보를 A9 나들이 일정에 "예약 필요" 표시로 자동 추가, 예약 완료 시 사용자가 체크
- 예약은 본인이 예약 사이트에서 직접 (자동 예약·매크로 없음)

## 기술 구조
- 수집기: 출처별 API 호출 하루 수 회, 새 항목·접수 시작 시각 추출, 중복 제거
- 매칭: 대상 연령 텍스트 파싱(예: "5~7세", "초등 저학년"), 장소 좌표 → 거리 계산
- 알림: A9 앱 푸시(안드로이드, 앱 내 업데이트) + 필요 시 텔레그램
- 저장: 프로그램·알림 이력, 가족 프로필(아이 생년, 지역, 관심사)
- 공유 부품: G4 지역 데이터 수집기·좌표 변환 재사용 가능

## 단계별 절차
| 단계 | 할 일 | 완료 기준 |
|---|---|---|
| 0. 출처 조사 | 지역(거주지 기준) 공공 예약 출처 목록, 공개 API 여부·이용 조건 확인 | API 사용 가능 출처 3곳 이상 |
| 1. 수집기 | 출처별 수집, 접수 시작 시각·대상 연령·장소 추출 | 7일간 누락 없이 수집 |
| 2. 매칭 | 아이 나이·거리·주말·가격 조건 필터 | 지난 한 달 데이터로 관심 있는 항목 정확히 선별 |
| 3. 알림 | 새 항목·전날·1시간 전 알림 | 테스트 프로그램 3건 정상 알림 |
| 4. A9 연동 | 후보를 나들이 일정에 자동 추가, 예약 완료 체크 | A9 화면에서 확인 가능 |
| 5. 실사용 | 한 달 사용, 놓친 접수·불필요 알림 점검 | 놓친 접수 0건 |
| 6. 확장 | 출처 추가(박물관·과학관 등), 형제 연령 다중 조건 | 출처 6곳 이상 |

## 법·정책 주의사항
- 공개 API·공개 데이터만 사용, 이용 조건·출처 표시 준수
- 자동 예약·매크로·과도한 호출 금지 (예약 시스템 공정성)
- 아이 생년·거주지 등 가족 정보는 기기·본인 계정에만 저장

## 리스크와 대응
- 출처마다 API가 없거나 형식이 다름 → API 있는 곳부터, 없는 곳은 공지 일정만 수동 등록 지원
- 대상 연령 표기가 제각각 → 파싱 실패 시 "확인 필요"로 표시
- 인기 프로그램은 알림을 받아도 마감 → 접수 1시간 전 알림 + 대체 후보 함께 제시
