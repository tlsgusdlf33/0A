# 78. 나들이 사진 월간 포토북 자동 편집·인쇄

> **A9 보완 제안 (2026-10-31)**: 사용자 개인 세션 A9(주말나들이 앱)에 추가 권장, 인쇄는 G6(39번, 30번 주문형 인쇄) 연동. 53번(동화 그림책 인쇄)과 같은 인쇄 연동 사용. 개인 세션이라 지시 시에만 전달. **A9 세션(session_01Eds9eFJn2dFHhadQFajQqV)에 전달 (2026-10-31 사용자 지시)** — 1차는 PDF까지, 30번 인쇄 연동은 준비되면 연결

## 최종 목표
- 매월 1일, 지난달 나들이 포토북 PDF 자동 완성 → 확인 후 버튼 한 번으로 인쇄 주문
- 사용자 편집 시간 5분 이하

## MVP 범위
- A9 나들이 일정(날짜·장소)과 폰 사진(촬영 시각·위치) 매칭
- 나들이별 베스트 사진 선별(흐림·중복·눈 감음 제외), 장소·날짜 캡션, 페이지 레이아웃
- 미리보기·교체 → 30번 인쇄 주문

## 단계별 절차
| 단계 | 할 일 | 완료 기준 |
|---|---|---|
| 0. 사진 접근 | 폰 사진 메타데이터 읽기 권한(앱 내) | 한 달치 사진 목록 |
| 1. 매칭·선별 | 일정 매칭, 품질·중복 필터 | 나들이별 사진 10장 선별 |

| 3. 인쇄 | 30번 주문형 인쇄 연동 | 실물 1권 수령 |
