# 65. 판매 사이트 세금계산서·현금영수증 자동 발행 연동

> **39번(G6) 보완 제안 (2026-10-26)**: G6 판매 인프라(39번 결제 엔진, 7·30번 판매 사이트)에 증빙 발행 모듈로 추가 권장. 월별 증빙은 28번(G1) 장부로 전달. **작업 대기 (사용량 절약)**

## 최종 목표
- 결제 완료 건의 증빙(현금영수증·전자세금계산서) 자동 발행률 100%, 환불 시 자동 취소
- 월 증빙 정리 시간 0분 (28번 장부로 자동 전달)

## MVP 범위
- 39번 결제 이벤트 → 발행 대행 API 호출(구매자 유형별: 개인 현금영수증 / 사업자 세금계산서)
- 환불 이벤트 → 취소·수정 발행, 실패 건 재시도·알림

## 단계별 절차
| 단계 | 할 일 | 완료 기준 |
|---|---|---|
| 0. 대행사 선택 | 발행 대행 API 비교(수수료·테스트 환경) | 대행사 결정 |
| 1. 발행 연동 | 결제 이벤트 → 발행, 테스트 환경 검증 | 테스트 결제 10건 발행 |
| 2. 취소 연동 | 환불 → 취소·수정 발행 | 테스트 환불 5건 처리 |
| 3. 장부 전달 | 월별 증빙 묶음 → 28번 | 월말 자동 전달 |

## 주의
- 사업자 등록·과세 유형에 따라 발행 의무 다름 → 세무 확인
