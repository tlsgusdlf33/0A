# 10. 소상공인 리뷰 답글 마이크로 SaaS

## 최종 목표
- **12개월 안에 유료 매장 30곳 (월 9,900원 기준 월 약 30만 원), 월 이탈률 5% 이하**
- 사장님 입장에서 리뷰 1건 처리 시간 **10초 이하** (확인 → 복사 또는 자동 게시)
- 운영은 주 2시간 이하 (문의 대응 포함)
- (42번 병합) **신규 개업 매장 리드**를 영업 채널로 활용해 고객 확보 비용을 낮추고, 같은 리스트를 B2B 영업자에게 판매하는 부가 수익: 출시 6개월 안에 리스트 유료 구독 10건

## MVP 범위
- 모바일 웹앱 (사장님은 주로 휴대폰 사용)
- 리뷰 입력: 텍스트 붙여넣기 또는 리뷰 화면 캡처 업로드(OCR)
- 가게 프로필(가게 이름, 사장님 호칭, 말투, 대표 메뉴, 쓰지 말 표현) 기반 답글 초안 2개 → 선택·수정 → 복사
- 별점·내용별 톤 조절, 악성·허위 의심 리뷰는 별도 대응 문구 + 플랫폼 신고 기준 안내

## 기술 구조
- 프론트·백엔드: Next.js (모바일 우선), 인증·DB는 Supabase
- 답글 생성: LLM + 가게 프로필 + 사장님이 승인한 과거 답글을 예시로 사용 (쓸수록 가게 말투에 가까워짐)
- 안전 필터: 개인정보 노출(전화번호·주소), 과장·허위 광고 표현, 리뷰어 비난 표현 차단
- 자동 연동: **공식 API가 있는 플랫폼만** (예: Google 비즈니스 프로필 API는 리뷰 조회·답글 기능 제공). 공식 API가 없는 플랫폼은 붙여넣기·캡처 방식 유지
  - 사장님 계정 비밀번호를 받아 자동 로그인하는 방식은 약관 위반·보안 사고 위험이 커서 하지 않음
- 결제: 국내 PG 정기결제(빌링), 첫 달 무료 체험
- 비용: 매장당 월 LLM 비용 수백 원~천 원대 예상 (리뷰 수에 따라)

## 단계별 절차
| 단계 | 할 일 | 완료 기준 |
|---|---|---|
| 0. 인터뷰 | 주변 가게 5곳: 하루 리뷰 수, 답글에 쓰는 시간, 사용하는 플랫폼, 가장 곤란한 리뷰 유형 | "얼마면 쓰겠다" 답변 3곳 이상 |
| 1. 프로토타입 | 붙여넣기 → 답글 2개 생성 → 복사, 가게 프로필 입력 | 실제 리뷰 50건으로 테스트, 그대로 쓸 만한 비율 70% 이상 |
| 2. 파일럿 | 가게 3곳 4주 무료 사용, 주간 사용 횟수·답글 수정률 측정 | 3곳 중 2곳이 매주 사용 |
| 3. 말투 학습 | 승인·수정된 답글을 예시로 축적, 금지 표현 사전 | 수정률이 첫 주 대비 절반으로 감소 |
| 4. 결제·요금제 | 정기결제, 무료 체험, 해지 버튼을 쉽게 | 파일럿 매장 중 1곳 이상 유료 전환 |
| 5. 공식 API 연동 | Google 비즈니스 프로필 등 공식 API 지원 플랫폼부터 자동 수집·게시 | 연동 매장은 새 리뷰 알림 → 승인 1번으로 게시 |
| 6. 알리기 | 파일럿 사장님 소개, 지역 상인 모임, 소상공인 커뮤니티 (홍보 규칙 준수) | 유료 매장 10곳 |
| 6-1. 신규 개업 리드 수집 (42번 병합) | 지방행정 인허가 공공데이터(음식점·카페·미용실 등)로 신규 개업·폐업을 매일 수집 → 지역·업종 필터 → 개업 1~4주 차 매장에 첫 달 무료 체험 안내(오프라인 방문·전단 위주, 무작위 전화·문자 금지) | 우리 구 신규 개업 리스트 매일 자동 생성, 리드 → 체험 전환율 측정 |
| 6-2. 리드 리스트 판매 (42번 병합) | 같은 리스트를 POS·인테리어·세무·마케팅 업체에 지역·업종별 구독으로 판매(엑셀·메일 자동 발송), 이용 약관에 무차별 연락 금지 명시 | 유료 구독 10건 |
| 7. 월간 리뷰 리포트 | 불만 키워드 상위 5개, 별점 추이, 칭찬 포인트 → 운영 개선 힌트 (해지 방지 장치) | 리포트 발송 후 이탈률 감소 |
| 8. 확장 | 다점포 요금제, 직원 계정, 리뷰 이벤트 문구 생성 | 유료 매장 30곳 |

## 법·정책 주의사항
- 각 리뷰 플랫폼의 운영 정책 준수: 자동화는 공식 API 범위 안에서만, 답글 내용은 사장님이 최종 승인
- 개인정보: 리뷰 작성자 닉네임 등은 답글 생성에 필요한 범위만 처리, 보관 기간 정책 명시
- 정기결제: 결제 주기·금액·해지 방법을 결제 전에 명확히 고지, 사업자 등록·통신판매업 신고
- AI 생성 답글이 법적 분쟁(허위 리뷰 대응 등)에 쓰일 수 있으므로 "법률 조언 아님" 안내
- 리드 리스트(42번 병합): 공공데이터 이용 조건(상업적 이용·재배포 범위) 확인, **사업장 정보만 사용하고 대표자 이름 등 개인정보는 제외**, 영리 목적 광고 전화·문자는 정보통신망법상 사전 동의가 필요하므로 리스트 구매자에게도 고지

## 리스크와 대응
- 자동 수집 불가 플랫폼이 많음 → 붙여넣기 UX를 극단적으로 쉽게 (공유하기 → 앱으로 보내기)
- 사장님 이탈 → 월간 리포트로 "답글 외 가치" 제공
- 큰 업체가 같은 기능 출시 → 작은 가게 전용 말투 학습·가격으로 차별화
