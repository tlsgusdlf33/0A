# 62. 공시가격 적정성 점검 & 의견 제출 초안 (보유세 절감)

> **1번(G4) 보완 제안 (2026-10-25)**: 1번 사이트의 실거래가·공시가격 데이터를 그대로 사용. G4(주 1번)에 기능으로 추가하는 것을 권장. **작업 대기 (2026-10-25 사용자 지시)**

## 최종 목표
- 매년 공시가격 열람 기간(3~4월) 전에 내 집 적정성 리포트 자동 완성
- 과도하게 높게 매겨진 경우 의견 제출서 초안 + 예상 보유세 차이 제시
- 1번 사이트 "우리 집 공시가 점검" 시즌 페이지로 트래픽 확보

## MVP 범위
- 내 집 vs 같은 단지·인근 유사 주택의 공시가/실거래가 비율 비교 (3년 추이)
- 기준 초과 시 열람 기간 알림, 근거 표·의견서 초안, 재산세·종부세 차이 계산

## 단계별 절차
| 단계 | 할 일 | 완료 기준 |
|---|---|---|
| 0. 데이터 | 공시가격·실거래가 공공데이터 범위·갱신 확인 | 수집 가능 확인 |
| 1. 비교 | 단지·유사 주택 비율 비교표 | 우리 집 3년치 표 완성 |
| 2. 판정·세금 | 과대 판정 기준, 보유세 차이 계산 | 실제 고지서와 오차 5% 이내 |
| 3. 초안·알림 | 의견 제출서 초안, 열람 기간 알림 | 다음 열람 기간 알림 발송 |
| 4. 사이트 | 1번 사이트 점검 페이지 (주소 입력 → 결과) | 페이지 공개 |

## 주의
- 의견 반영 여부는 보장되지 않음, 세액은 참고용
