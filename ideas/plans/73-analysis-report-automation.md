# 73. 해석(Analysis) 보고서 자동 작성

> **A6 보완 제안 (2026-10-30)**: 사용자 개인 세션 'A6. Analysis 보고서'(session_01P85PUVTNqN3h9J9vM2wNf4, 레포 A6)의 보고서 가이드라인(Vertical_Pump_Analysis_Report_Guideline.docx)을 양식으로 사용. 개인 세션이라 지시 시에만 전달. **작업 대기 (사용량 절약)**

## 최종 목표
- 해석 결과 → 가이드라인 양식 보고서 초안을 10분 안에 생성 (기존 수작업 반나절)
- 판정표 수치 오류 0건 (결과 파일 값과 자동 대조)

## MVP 범위
- 입력: 해석 프로그램 결과 파일(고유진동수·모드, 응력·변위, 진동 응답), 설계 조건(허용치·운전 속도)
- 자동 채움: 해석 조건·모델 요약, 결과 표, 허용치 대비 여유율 판정표, 그래프, 결론 초안
- 출력: 가이드라인 양식 DOCX (사람 검토 후 제출)

## 단계별 절차
| 단계 | 할 일 | 완료 기준 |
|---|---|---|
| 0. 양식 분석 | 가이드라인 항목·표 구조 → 템플릿화 | 템플릿 완성 |
| 1. 결과 파서 | 사용 중인 해석 프로그램 1종 결과 파일 읽기 | 과거 보고서 1건 값 재현 |
| 2. 판정·그래프 | 여유율 계산(공진 회피 마진 등), 그래프 | 판정표 자동 생성 |
| 3. 보고서 생성 | DOCX 출력, 결론 초안 | 과거 보고서와 비교 검토 |

## 주의
- 회사 해석 자료·도면은 외부 서버로 보내지 않음(로컬 처리), 최종 판정 책임은 작성자
