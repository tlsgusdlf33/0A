# 33. 보유 종목 공시 AI 요약 & 위험 신호 알림

> **통합됨 (2026-10-16)**: 이 프로젝트는 묶음 G3 투자 비서의 일부로 **25번 세션에서 개발**합니다 (주 계획: `25-etf-rebalancing-assistant.md`). 아래 내용은 그 세션의 모듈 요구사항으로 유지됩니다.

## 최종 목표
- **보유 종목 공시를 장중 5분 안에 감지**해서 알림
- 위험 공시(유상증자, 전환사채, 감사의견 문제 등) **놓침 0건**
- "긴급" 알림의 적중률(본인이 보기에 실제로 중요했던 비율) 80% 이상, 하루 평균 즉시 알림 3건 이하 (나머지는 저녁 요약)
- 매매는 자동으로 하지 않음

## MVP 범위
- 보유 종목 목록(25번 잔고 동기화 또는 수동 목록)
- DART 공시 목록 폴링 → 보유 종목만 필터 → 유형 분류 → 규칙 기반 위험도 + AI 3줄 요약 → 텔레그램

## 기술 구조
- 공시 데이터: DART Open API (19번과 같은 인증키·엔진 재사용)
  - 공시 목록은 종목별이 아니라 **당일 전체 목록을 1~2분 간격으로 조회**해서 보유 종목만 거르는 방식 (호출 수 절약, 호출 한도 확인)
  - 유상증자·전환사채 발행 등은 DART의 주요사항보고서 구조화 API로 수치(발행 주식 수, 발행가, 전환가액 등)를 직접 받아 계산
  - 종목코드 ↔ DART 고유번호는 DART 기업코드 파일로 매핑
- 위험 판정 규칙 (설정 파일로 관리):
  | 유형 | 판정 기준 예 |
  |---|---|
  | 유상증자 | 배정 방식(주주·제3자·일반), 할인율, **기존 주식 대비 희석률** |
  | 전환사채·신주인수권부사채 | 잠재 희석률, 전환가액 조정(리픽싱) 조건 |
  | 감사의견·상장 관련 | 한정·부적정·의견거절, 관리종목·거래정지·불성실공시 |
  | 지배구조 | 최대주주 변경, 횡령·배임 |
  | 긍정 신호 | 자기주식 취득·소각, 매출 대비 큰 공급계약, 배당 증가 |
- 영향 계산: 내 보유 평가액 × 희석률, 계약 금액 / 최근 매출
- AI 요약: 구조화되지 않은 공시만 LLM으로 유형 분류 + 3줄 요약, **원문 링크와 핵심 수치를 항상 함께 표시**
- 알림: 텔레그램 심각도 3단계(긴급 즉시 / 주의 즉시 / 참고는 저녁 요약), 장 마감 후·주말은 묶어서
- 보정: 과거 공시와 다음 거래일 주가 반응으로 규칙 가중치 점검
- 연동: 19번(DART 엔진), 25번(잔고), 31번 kit(notify·llm·ops 모듈)
- 비용: LLM은 비구조화 공시에만 → 월 소액

## 단계별 절차
| 단계 | 할 일 | 완료 기준 |
|---|---|---|
| 0. 준비 | DART 인증키(19번과 공유), 기업코드 매핑, 호출 한도 확인 | 보유 종목 → 고유번호 매핑 완료 |
| 1. 보유 종목 동기화 | 25번 잔고 API 또는 수동 목록, 매일 장 시작 전 갱신 | 목록 자동 갱신 |
| 2. 공시 감지 | 장중 1~2분 간격 전체 목록 조회 → 신규 건 중 보유 종목만 | 테스트에서 공시 후 5분 내 감지 |
| 3. 구조화 공시 처리 | 유상증자·사채 발행 등 구조화 API로 희석률 계산 | 과거 사례 20건 계산값을 원문과 대조해 일치 |
| 4. 위험 규칙 | 유형별 위험도 규칙 설정 파일, 긍정·부정·중립 판정 | 과거 공시 100건 판정 직접 검수 90% 일치 |
| 5. AI 요약 | 비구조화 공시 분류·요약, 수치는 원문에서 다시 확인 | 요약에 원문에 없는 수치 0건 |
| 6. 알림 설계 | 심각도별 즉시·저녁 요약, 내 보유분 영향 금액 표시 | 2주 실사용, 즉시 알림 하루 3건 이하 |
| 7. 보정 | 과거 공시 후 주가 반응과 본인 피드백("중요/불필요" 버튼)으로 규칙 조정 | 긴급 적중률 80% 이상 |
| 8. 확장 | 관심 종목(미보유) 감시 목록, 19번 공모주 상장 후 자동 편입 | 감시 목록 기능 |

## 법·정책 주의사항
- **본인용**: 판정·요약을 다른 사람에게 제공해 매매를 권하면 투자자문 규제 대상
- DART API 이용약관(호출 한도, 데이터 이용 조건) 준수, 공시 원문을 재배포하지 않음
- AI 요약·판정은 참고용이며 투자 판단 책임은 본인, 자동 매매 없음

## 리스크와 대응
- AI 요약 오류 → 핵심 수치는 구조화 API·원문 파싱 값만 사용, LLM은 문장 요약에만
- 알림 과다 → 심각도 기준·저녁 요약·조용한 시간
- DART 지연·장애 → 감지 지연이 길어지면 운영 알림(26번)
