# 71. 지원사업 사업계획서 초안 자동 작성

> **20번 보완 제안 (2026-10-29)**: 20번(정부 창업 지원사업 매칭)에 신청서 작성 기능으로 추가 권장. 44번(나라장터 제안서) 엔진과 같은 문서 생성 부품 사용. 입력 자료는 A10 레포 `ideas/plans/`. **작업 대기 (사용량 절약)**

## 최종 목표
- 공고 1건의 사업계획서 초안을 30분 안에 완성 (사람 수정 1~2시간)
- 12개월 안에 지원 5건, 선정 1건 이상

## MVP 범위
- 입력: 공고 신청 양식(HWP/HWPX·DOCX), 지원할 프로젝트의 계획 문서(plans/NN), 사용자 실적(A1 이력서)
- 자동 채움: 문제 인식, 해결 방안·차별성, 시장·경쟁, 추진 일정, 예산 사용 계획, 팀 구성
- 출력: 양식 그대로의 HWPX·DOCX 초안, 평가 항목별 보강 필요 표시

## 단계별 절차
| 단계 | 할 일 | 완료 기준 |
|---|---|---|
| 0. 양식 수집 | 자주 나오는 지원사업 양식 3종 구조 분석 | 항목 매핑표 |
| 1. 자료 연결 | plans/ 문서 → 양식 항목 매핑 | 프로젝트 1개 매핑 완료 |
| 2. 초안 생성 | 항목별 초안 + 분량 맞춤 | 양식 분량 제한 준수 |
| 3. 출력 | HWPX·DOCX 원본 양식 유지 | 서식 깨짐 0건 |
| 4. 실제 지원 | 공고 1건에 사용 → 수정 시간 기록 | 제출 완료 |

## 주의
- 허위·과장 실적 금지 (등록된 실제 자료만 사용), 제출은 본인이 직접
