# 84. 아이 성장 단계별 육아용품 판매 시점 알림

> **21번(G5) 보완 (2026-11-02 사용자 지시로 21번 세션에 전달)**: 21번 시세 엔진·판매글 초안 재사용, 27번 흡수분과 같은 G5.

## 최종 목표
- 육아용품을 사용 종료 1~2개월 전에 판매해 회수율(구매가 대비 판매가) 향상
- 판매 시점 알림·판매글 초안 자동

## MVP 범위
- 아이 생년월일 + 보유 육아용품 목록(사진 등록) → 품목별 사용 종료 시점 예측(연령·체중 기준표)
- 시점 1~2개월 전 중고 시세 확인 → 판매 권장 알림 + 판매글 초안 (게시는 본인)

## 단계별 절차
| 단계 | 할 일 | 완료 기준 |
|---|---|---|
| 0. 기준표 | 품목별 사용 연령·체중 기준 | 주요 품목 20종 |
| 1. 등록 | 사진으로 품목 등록(21번 식별) | 등록 1분 이내 |
| 2. 알림 | 종료 예측·시세 확인·알림 | 테스트 알림 정상 |

## 주의
- 안전 관련 용품(카시트 등)은 사고 이력·유효기간 고지 안내 포함
