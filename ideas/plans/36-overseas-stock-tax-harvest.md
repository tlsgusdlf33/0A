# 36. 해외주식 양도세 기본공제 활용 & 손익통산 알림

> **통합됨 (2026-10-16)**: 이 프로젝트는 묶음 G3 투자 비서의 일부로 **25번 세션에서 개발**합니다 (주 계획: `25-etf-rebalancing-assistant.md`). 아래 내용은 그 세션의 모듈 요구사항으로 유지됩니다.

## 최종 목표
- **실현할 이익이 있는 해에는 해외주식 양도소득 기본공제(연 250만 원)를 100% 활용**
- 여러 증권사에 흩어진 손익을 합산해, 연말 마지막 매도 가능일 전에 "세금 없이 실현 가능한 이익"과 "상계할 손실"을 자동 제시
- 예상 양도세가 증권사 계산과 오차 5% 이내, 5월 신고 누락 0건
- 연말 판단 작업 **10분 이하** (알림 확인 → 승인 또는 직접 주문)

## MVP 범위
- 해외주식 보유 증권사 전부의 매매내역·잔고 합산 (API가 있는 곳은 API, 없는 곳은 거래내역 파일)
- 올해 실현손익, 종목별 평가손익, 기본공제 잔여액 계산
- 11~12월 시나리오 알림: 이익 실현 / 손실 확정 / 혼합

## 기술 구조
- 데이터:
  - 25번 증권사 Open API (해외주식 체결·잔고 조회)
  - API가 없는 증권사는 양도세 신고용 매매내역 파일(CSV·엑셀) 업로드
  - 환율: 한국은행 ECOS API (28번과 공유) — **취득·양도 시점 환율이 각각 적용돼 환차손익도 과세 대상에 포함**
- 계산 규칙은 설정 파일 (31번 kit 레지스트리 연동):
  - 기본공제 금액, 세율(지방세 포함 22%), 취득가 산정 방식(선입선출 등 — 세무 확인 후 설정), 과세 연도 귀속 기준(결제일)
  - **국내 상장 해외 ETF는 과세 방식이 달라 계산 대상에서 제외**
- 연말 마감일 계산: 해외 시장 결제 주기와 양국 휴장일을 반영해 "올해 귀속 마지막 매도일" 자동 계산
- 시나리오 엔진: 종목·로트별 손익을 조합해 "공제 잔여분만큼 이익 실현", "손실로 이익 상계" 후보와 예상 세액 비교
- 실행: 알림만 기본, 원하면 25번 승인형 주문 흐름 재사용
- 비용: 0원

## 단계별 절차
| 단계 | 할 일 | 완료 기준 |
|---|---|---|
| 0. 기준 확인 | 세무 확인: 취득가 산정 방식, 환율 적용 기준, 매도 후 재매수 전략의 문제 여부, 증권사 신고대행 이용 여부 | 설정 파일에 기준 기록 |
| 1. 데이터 수집 | 증권사별 API·파일로 올해 체결·보유 로트 수집, 통화·수수료 포함 | 모든 증권사 데이터가 한 표로 합쳐짐 |
| 2. 손익 계산 | 로트별 원화 기준 취득가·양도가(환율 반영), 실현손익 YTD, 평가손익 | 증권사 제공 실현손익과 오차 5% 이내 |
| 3. 마감일 계산 | 결제 주기·휴장일로 올해 귀속 마지막 매도일 계산 | 최근 3년 연말 마감일을 공개 안내와 대조해 일치 |
| 4. 시나리오 엔진 | 공제 잔여분 실현, 손실 상계, 혼합 시나리오별 예상 세액·실현 금액 | 시나리오 3종 리포트 |
| 5. 알림 | 10월 중간 점검, 11월 시나리오 제안, 마지막 매도일 D-10·D-3, 1월 확정 요약 | 연말 1회 실사용 |
| 6. 신고 지원 | 5월 신고용 요약(증권사별 손익, 합산 과세표준, 예상 세액), 증권사 신고대행 신청 안내 | 신고 누락 0건 |
| 7. 연동 | 25번(리밸런싱 매도와 세금 조율), 28번(5월 신고 시즌 함께 안내), 33번(보유 종목 데이터 공유) | 리밸런싱 매도 제안에 양도세 영향 표시 |

## 법·정책 주의사항
- 세금 계산은 추정치: 최종 신고 내용은 본인·세무사·증권사 신고대행 결과로 확인
- 매도 후 재매수로 취득가를 높이는 전략은 세법상 문제 여부를 세무 확인 후에만 사용
- 본인 계좌용 도구: 다른 사람에게 절세 매매를 권하는 서비스로 제공하면 투자자문 규제 대상
- 금융 데이터는 로컬·비공개 보관

## 리스크와 대응
- 증권사마다 내역 파일 형식이 다름 → 증권사별 파서 분리, 합계 검증 실패 시 알림
- 환율 적용 기준 착오 → 설정 파일로 고정하고 증권사 계산값과 매년 대조
- 연말 시장 급변 → 시나리오는 제안일 기준이므로 실행 직전 재계산
