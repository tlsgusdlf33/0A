# 59. 동네 유치원·어린이집 비교 페이지 + 입학 일정 알림

> **1번(G4) 보완(병합 제안) (2026-10-24)**: 묶음 G4 지역 데이터 플랫폼(주 프로젝트 1번 공공데이터 자동 갱신 사이트, 29번 흡수)에 새 페이지 유형으로 추가하는 것을 권장합니다. 같은 지역 데이터 수집기·좌표 변환·동네 뉴스레터(38번 병합분)를 공유합니다. 사용자가 병합을 지시하면 1번 세션으로 전달합니다.

## 최종 목표
- 1번 사이트에 **동네(읍면동)별 유치원·어린이집 비교 페이지 자동 생성**, 데이터 갱신 시 자동 반영
- 입학 시즌(10~12월) 검색 유입으로 사이트 월 방문 증가 → 광고·뉴스레터 구독 수익 증대
- 우리 아이 입학 준비: 처음학교로 신청 기간·추첨·등록 일정 **놓침 0건**, 우리 집 기준 맞춤 비교표 완성
- 운영 시간: 월 0분 (수집·생성·알림 자동)

## MVP 범위
- 데이터(공시·공공데이터 우선):
  - 유치원알리미 공시 정보(교육비·급식·통학 차량·학급·교사 수·방과후 과정)
  - 어린이집 정보공개(보육 정원·현원·교사 대 아동 비율·평가 등급·차량 운행)
  - 처음학교로 입학 일정(지역 교육청 공지 기준)
- 페이지: 동네별 목록 → 기관별 상세(항목 비교표·지도·데이터 기준일), 기관 2~3곳 비교 화면
- 맞춤 비교(본인용): 우리 집 주소 기준 거리·도보 시간·통학 차량 노선 여부·월 부담액 → 순위표
- 알림: 입학 신청 시작·마감·추첨 결과·등록 기간 (텔레그램 또는 1번 사이트 알림 구독)
- 수익: 1번 사이트 광고, 입학 시즌 특집 뉴스레터(38번 동네 뉴스레터에 섹션)

## 기술 구조
- 1번 사이트의 수집 파이프라인에 수집기 추가(공공데이터 API·공시 데이터 내려받기), 일·주 단위 갱신
- 주소 → 좌표 변환(G4 공유 부품), 거리·도보 시간 계산
- 정적 페이지 자동 생성(1번 사이트 기존 생성기), 데이터 기준일·출처 표시
- 알림: 1번 사이트 "관심 지점 알림"(29번 흡수 기능) 구조 재사용 → "관심 기관·입학 일정 알림"
- 개인 맞춤 비교는 공개 페이지와 분리(본인 계정·로컬)

## 단계별 절차
| 단계 | 할 일 | 완료 기준 |
|---|---|---|
| 0. 데이터 확인 | 유치원알리미·어린이집 정보공개 API/파일 제공 범위, 이용 조건·출처 표시 의무 확인 | 사용할 항목 목록 확정 |
| 1. 수집기 | 1번 파이프라인에 수집기 추가, 거주 시·군·구부터 | 해당 지역 전 기관 수집 |
| 2. 페이지 | 동네별 목록·기관 상세·비교 화면 자동 생성 | 사이트에 게시, 데이터 기준일 표시 |
| 3. 맞춤 비교 | 우리 집 기준 거리·차량·월 부담액 순위표 | 본인용 비교표 완성 |
| 4. 입학 일정 알림 | 처음학교로·교육청 일정 → 단계별 알림 | 이번 입학 시즌 알림 정상 발송 |
| 5. 수익 연결 | 광고 위치, 뉴스레터 입학 특집 섹션 | 페이지 방문·구독 지표 측정 |
| 6. 확장 | 전국 확대(데이터 자동화가 되면 지역 추가 비용 0), 초등학교 학군 정보 검토 | 시·도 단위 확대 |

## 법·정책 주의사항
- 공시·공공데이터 이용 조건과 출처 표시 준수, 데이터 기준일 명시 (실시간 정보 아님)
- 기관 평가·순위는 공개 페이지에서 단정적 표현 금지 (공시 수치 나열·비교만), 명예훼손 소지 차단
- 아이·가족 정보는 공개 페이지에 쓰지 않고 본인용 비교에만

## 리스크와 대응
- 공시 데이터 갱신 주기가 김 → 기준일 표시, 기관 정보 변경 제보 링크
- 입학 일정 형식이 지역마다 다름 → 거주 지역부터 수동 보정 규칙, 이후 확장
- 시즌성 트래픽 → 입학 외 기간에는 방과후·놀이시설 등 연관 페이지로 보완
