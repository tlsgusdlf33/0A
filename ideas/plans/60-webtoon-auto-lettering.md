# 60. 웹툰 대사 자동 식자 (말풍선 배치·한글 레터링)

> **A22 보완 제안 (2026-10-24)**: 사용자 개인 세션 A22(소설을 웹툰으로 수익화)의 콘티·대본과 완성 컷을 입력으로 씁니다. A22 레포에 `lettering/` 모듈로 두는 것을 권장합니다. 48번(웹소설 번역 전자책)과 연결하면 번역 대사로 식자만 다시 해 해외판을 만들 수 있습니다. 개인 세션이라 사용자가 지시할 때만 전달합니다.

## 최종 목표
- 1화(약 60컷) 식자 작업 시간 **수 시간 → 30분 이하** (자동 배치 + 사람 검수)
- 자동 배치 후 위치를 고쳐야 하는 말풍선 비율 **20% 이하** (회차가 쌓일수록 감소)
- 말풍선이 얼굴·핵심 동작을 가리는 사례 0건 (검수 단계에서 경고)
- 번역 대사로 바꿔 식자하는 해외판 1화 제작 시간 15분 이하

## MVP 범위
- 입력: A22 콘티(컷 번호·대사·말하는 인물·대사 종류: 대화/생각/나레이션/효과음), 완성된 컷 이미지
- 인식: 컷별 얼굴·인물·주요 물체 위치, 여백 영역, 말하는 인물 위치
- 배치: 읽는 순서(위→아래, 대화 순서) 유지, 말하는 인물 쪽으로 꼬리 방향, 가리지 않는 여백에 배치, 크기는 글자 수에 맞춰 자동
- 레터링: 한글 웹툰 글꼴(라이선스 확인된 글꼴), 어절 단위 줄바꿈, 대사 종류별 말풍선 모양(대화 원형, 생각 구름형, 나레이션 사각)
- 출력: 수정 가능한 레이어 파일(PSD 또는 SVG 레이어), 세로 스크롤 완성 이미지(플랫폼 규격 폭)
- 검수 화면: 경고(가림·겹침·글자 넘침) 표시, 말풍선 드래그로 위치 수정

## 기술 구조
- 처리: Python, 얼굴·인물 검출 모델 + 여백(배경 단순 영역) 계산, 배치 최적화(가림 비용·읽기 순서·꼬리 거리 점수)
- 렌더링: 글꼴 렌더링으로 줄바꿈·크기 계산, 말풍선 벡터 도형 생성
- 출력: psd 레이어 쓰기 라이브러리 또는 SVG, 세로 이미지 합성
- 학습: 사람이 수정한 위치를 기록 → 다음 배치 점수 가중치 조정
- 실행: PC(무거운 처리) + 폰에서 결과 미리보기 (사용자 선호)

## 단계별 절차
| 단계 | 할 일 | 완료 기준 |
|---|---|---|
| 0. 입력 형식 | A22 콘티·대본·컷 이미지 형식 확인, 글꼴 라이선스 확인 | 입력 규격 확정 |
| 1. 인식 | 컷별 얼굴·인물·여백 검출 | 샘플 20컷에서 인물 위치 정확 |
| 2. 배치 | 읽기 순서·가림 방지·꼬리 방향 배치 | 수정 필요 비율 30% 이하(1차) |
| 3. 레터링 | 글꼴·줄바꿈·말풍선 모양 | 글자 넘침 0건 |
| 4. 출력 | 레이어 파일·세로 스크롤 이미지 | 플랫폼 업로드 규격 충족 |
| 5. 검수 화면 | 경고 표시·드래그 수정·수정 이력 저장 | 1화 검수 30분 이내 |
| 6. 학습 반영 | 수정 이력으로 배치 가중치 조정 | 3화 후 수정 비율 20% 이하 |
| 7. 해외판 | 48번 번역 대사로 식자 교체 (영어 글꼴·가로 길이 차이 대응) | 영어판 1화 15분 이내 |

## 법·정책 주의사항
- 글꼴은 상업용 사용이 허용된 라이선스만 사용
- 연재 플랫폼의 AI 사용 표기 정책 확인 (식자 자동화는 보조 도구로 사용)
- 원작(A20)·작화 권리는 사용자 소유인 것만 사용

## 리스크와 대응
- 복잡한 장면(여백 부족)에서 배치 실패 → 컷 확장·말풍선 축소·나레이션 박스 대안 제시, 마지막은 사람 수정
- 그림체에 따라 얼굴 인식 정확도 차이 → A22 그림체 샘플로 검출 기준 조정
- 세로 스크롤 연출(긴 컷)에서 읽기 순서 오류 → 콘티의 대사 순서를 우선 규칙으로 사용
