# 67. 스톡 사진 판매 데이터 기반 촬영 주제 추천

> **13번 보완 제안 (2026-10-27)**: 13번(스톡 사진 판매 파이프라인) 레포에 분석 모듈로 추가 권장. 13번 세션에 병합 지시 시 전달. **작업 대기 (사용량 절약)**

## 최종 목표
- 월 1회 "잘 팔리고 경쟁 적은 주제" 촬영 목록 자동 작성
- 6개월 뒤 사진 1장당 평균 판매액 30% 향상

## MVP 범위
- 입력: 13번 업로드·판매 기록(사이트별 보고서), 스톡 사이트 공개 검색 결과 수(경쟁도)
- 출력: 키워드별 판매율·경쟁도 표, 촬영 목록, 내 폴더의 비슷한 미업로드 사진 후보

## 단계별 절차
| 단계 | 할 일 | 완료 기준 |
|---|---|---|
| 0. 데이터 | 사이트별 판매 보고서 형식 확인 | 3개월치 집계 |
| 1. 집계 | 키워드별 판매율·경쟁도 | 키워드 순위표 |
| 2. 추천 | 촬영 목록 + 미업로드 사진 후보 | 월간 리포트 자동 생성 |
| 3. 검증 | 추천 주제 업로드분 vs 기존 판매 비교 | 3개월 비교 |

## 주의
- 스톡 사이트 이용약관 범위 안에서 공개 정보만 조회 (과도한 크롤링 금지)
