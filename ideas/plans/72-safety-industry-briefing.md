# 72. 건설기계·산업안전 전용 출퇴근 브리핑 채널

> **8번 보완 제안 (2026-10-29)**: 8번(출퇴근 맞춤 오디오 브리핑, 이미 APK 출시)에 직무 채널로 추가 권장. 법령 개정 감지는 31번(G7) 세법·제도 변경 감지 방식 재사용, 수집한 사고 사례는 46·55번 위험 요인 라이브러리로 전달. **작업 대기 (사용량 절약)**

## 최종 목표
- 매일 5분 직무 브리핑 자동 생성 (사람 손 0분)
- 산업안전보건법·건설기계관리법 관련 개정·고시를 공포 후 3일 안에 100% 브리핑

## MVP 범위
- 출처: 국가법령정보 Open API(법령·고시 개정), 고용노동부·안전보건공단 공지·사고 속보, 업계 뉴스 RSS
- 요약: 오늘 바뀐 규정·주요 사고 1건·업계 소식 3건 → 오디오(8번 TTS) + 텍스트
- 연동: 사고 사례를 46·55번 라이브러리 갱신 후보로 저장

## 단계별 절차
| 단계 | 할 일 | 완료 기준 |
|---|---|---|
| 0. 출처 | 법령 API·공지·RSS 목록, 이용 조건 확인 | 출처 5곳 |
| 1. 수집·감지 | 개정·고시 감지, 사고 속보 수집 | 1주일간 누락 0건 |
| 2. 요약·오디오 | 8번 파이프라인에 채널 추가 | 매일 5분 브리핑 생성 |
| 3. 라이브러리 연동 | 사고 사례 → 46·55번 후보 | 후보 자동 저장 |

## 주의
