# 45. 한국형 웹 접근성(KWCAG 2.2) 자동 점검 & 수정 가이드 SaaS

> **병합 제안 (2026-10-17)**: 묶음 G7(주 프로젝트 31번)에 병합하는 것을 권장합니다. 31번은 이미 "CI에서 위험한 코드를 막는 가드레일"이 핵심이라 접근성 검사를 같은 CI 가드로 넣기 쉽고, 흡수된 26번의 주기 점검 스케줄러로 고객 사이트 정기 크롤링을 돌릴 수 있습니다. G6(39번 보일러플레이트)와 7·30번 판매 사이트는 이 검사를 CI에서 가져다 써서 "접근성 기본 준수"를 상품 차별점으로 씁니다. 사용자가 병합을 지시하면 31번 세션으로 전달합니다.

## 최종 목표
- 12개월 안에 유료 고객 20곳 (사이트당 월 19,000원부터, 월 약 40만 원)
- 자동 검사 가능한 KWCAG 2.2 항목에서 **오탐률 5% 이하**
- 내 프로젝트(1·7·10·30·39번 웹)에서 자동 검사 가능한 항목 위반 0건 유지 (CI 차단)
- 운영은 주 2시간 이하

## MVP 범위
- URL 입력 → 최대 50페이지 크롤링 → 항목별 위반 목록
- 리포트: KWCAG 2.2 항목 번호, 위반 위치(선택자·스크린샷), **한국어 수정 코드 예시**, 심각도
- 월 1회 자동 재검사 + 개선 추이 그래프
- 자동 검사로 판단할 수 없는 항목은 "사람 확인 필요" 체크리스트로 분리
- CI용 명령줄 도구: PR마다 변경된 페이지 검사, 기준 초과 시 실패

## 기술 구조
- 검사 엔진: Playwright(헤드리스 Chromium) + axe-core 규칙 → **KWCAG 2.2 항목 대응표**로 재분류, 한국어 메시지·수정 예시 추가
- 추가 규칙(국내 사이트에서 흔한 문제): 이미지 대체텍스트 품질(파일명·"이미지" 같은 무의미 텍스트), 본문 바로가기 링크, 언어 속성 ko, 초점 표시 제거, 자동 재생 슬라이드 정지 기능, 표 제목·머리글
- 명도대비·키보드 이동 순서: 렌더링 후 계산, 키보드 탭 순서 자동 탐색
- 저장: Postgres(고객·검사 기록), 스크린샷은 오브젝트 저장소
- 결제: G6 39번 결제·정기결제 엔진 사용
- 정기 실행: 26번(31번에 흡수) 스케줄러·운영 연동
- 비용: 크롤링 서버 월 수만 원 이내로 시작

## 단계별 절차

|---|---|---|
| 0. 기준 정리 | KWCAG 2.2 전 항목을 "자동 / 반자동 / 사람 확인"으로 분류, axe-core 규칙 대응표 작성 | 대응표 완성, 자동 항목 범위 명시 |
| 1. 검사 엔진 | Playwright + axe-core 실행, KWCAG 항목으로 재분류, 국내 추가 규칙 5개 | 테스트 페이지 세트에서 기대 위반 100% 검출 |
| 2. 오탐 검증 | 공개 사이트 20곳(쇼핑몰·기관) 검사 결과를 직접 확인 | 오탐률 5% 이하 |
| 3. 리포트 | 항목별 위반·위치·스크린샷·한국어 수정 예시, PDF 내보내기 | 개발자가 리포트만 보고 수정 가능 |
| 4. CI 도구 | 31번 kit에 CI 가드로 추가, 39번 템플릿과 7·30번 사이트에 적용 | 위반이 있는 PR이 CI에서 실패 |
| 5. 정기 재검사 | 월 1회 자동 재검사, 추이 그래프, 새 위반 알림 | 3개월 연속 자동 실행 |

| 8. 확장 | 모바일 앱 접근성(안드로이드 접근성 검사) 검토, 사람 확인 체크리스트를 대행하는 유료 옵션 | 확장 여부 결정 |

## 법·정책 주의사항
- 이 서비스는 **사전 점검 도구**이며 웹 접근성 품질인증을 대체하지 않음 → 리포트·약관에 명시
- 고객이 소유·관리 권한을 가진 사이트만 검사 (도메인 소유 확인), 크롤링 속도 제한과 robots.txt 준수
- 무료 진단 영업 시 남의 사이트 위반 내용을 공개하지 않음

## 리스크와 대응
- 자동 검사 범위가 제한적 → "자동 + 사람 확인 체크리스트"로 정직하게 안내, 사람 확인 항목은 유료 옵션
- 무료 도구(Lighthouse·axe 확장)와 비교됨 → 국내 지침 기준 리포트, 한국어 수정 예시, 정기 재검사·CI 통합으로 차별화
- 동적 사이트(로그인 뒤 페이지) 검사 어려움 → 고객이 테스트 계정·시나리오를 등록하는 기능은 2차로
