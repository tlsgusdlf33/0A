# 68. 동네 가게 개업·폐업 소식 페이지

> **1번(G4) 보완 제안 (2026-10-27)**: 42번(10번 병합분) 지방행정 인허가 수집기를 재사용해 1번 사이트 콘텐츠로 추가 권장. **작업 대기 (사용량 절약)**

## 최종 목표
- 구·동별 개업·폐업·업종 변화 월간 페이지 자동 생성 (운영 0분)
- 동네 뉴스레터 고정 섹션으로 구독 유지율 향상

## MVP 범위
- 인허가 데이터(음식점·카페·미용 등) → 개업·폐업 목록, 지도, 업종별 증감 차트
- 1번 사이트 페이지 + 38번 동네 뉴스레터 섹션

## 단계별 절차
| 단계 | 할 일 | 완료 기준 |
|---|---|---|
| 0. 수집기 공유 | 10번(42번) 수집 코드 → G4 공용 수집기로 | 거주 구 데이터 수집 |
| 1. 페이지 | 월간 개업·폐업 목록·지도·차트 | 사이트 게시 |
| 2. 뉴스레터 | 동네 뉴스레터 섹션 자동 삽입 | 다음 호 발송 |
| 3. 확장 | 다른 구·시로 확대 | 지역 추가 비용 0 |
