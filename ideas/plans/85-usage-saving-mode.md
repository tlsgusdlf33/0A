# 85. 사용량 절감 모드 (로컬 처리 우선 + 사용량 대시보드)

> **로컬 AI 코드 에디터 세션 보완 제안 (2026-11-03)**: 사용자 개인 세션 '로컬 AI 코드 에디터 개발'(session_01P85PUUrfHMxB8hGuD7rq6c, 레포 Claude-code)에 기능으로 추가 권장. 개인 세션이라 지시 시에만 전달. **작업 대기**

## 최종 목표
- 같은 작업량 기준 클라우드 토큰 사용량 30% 이상 절감
- 주간 한도 소진 시점을 3일 전에 예측·경고

## MVP 범위
- 작업 라우팅 규칙: 파일 검색·포맷·린트·간단 치환 → 로컬 도구/로컬 모델, 설계·복잡 수정 → 클라우드
- 큰 출력(로그·목록·검색 결과) 자동 요약·잘라내기 후 전달
- 작업별 토큰 기록, 일·주 사용량 그래프, 한도 대비 소진 예측

## 단계별 절차
| 단계 | 할 일 | 완료 기준 |
|---|---|---|
| 0. 측정 | 현재 작업 유형별 토큰 사용량 1주 기록 | 기준선 확보 |
| 1. 라우팅 | 로컬 처리 규칙 + 수동 전환 버튼 | 단순 작업 70% 로컬 처리 |
| 2. 출력 요약 | 큰 출력 자동 요약 | 컨텍스트 크기 감소 확인 |
| 3. 대시보드 | 사용량 그래프·소진 예측 경고 | 1주 비교로 30% 절감 |

## 주의
- 로컬 모델 품질 한계 → 결과 검증 후 실패 시 클라우드로 자동 재시도
