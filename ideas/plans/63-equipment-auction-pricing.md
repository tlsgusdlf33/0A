# 63. 건설기계·중장비 공매 특화 시세·입찰 판단

> **21번(G5) 보완 제안 (2026-10-25)**: G5(주 21번, 27번 온비드 공매 흡수)의 시세 엔진에 건설기계 감가 규칙(사용자 직무 지식)을 추가. 52번 장비 사업자 고객에게도 정보 제공 가능. **작업 대기 (2026-10-25 사용자 지시)**

## 최종 목표
- 온비드 건설기계·화물차 공매 물건 100% 수집, 물건별 적정 입찰가·예상 차익 자동 계산
- 지난 낙찰 결과 대비 적정 입찰가 오차 15% 이내

## MVP 범위
- 기종·연식·가동시간 감가 규칙, 국내 중고 시세(수출 시세는 공개 출처 확인 후)
- 정비 예상 비용, 되팔 경로(국내·수출) 비교, 입찰 마감 알림

## 단계별 절차
| 단계 | 할 일 | 완료 기준 |
|---|---|---|
| 0. 낙찰 분석 | 온비드 지난 6개월 건설기계 낙찰가율 | 기종별 낙찰가율 표 |
| 1. 감가 규칙 | 기종·연식·가동시간별 감가표 | 표본 20건 시세와 오차 15% 이내 |
| 2. 입찰가 계산 | 시세 − 정비비 − 비용 − 목표 마진 | 물건별 적정 입찰가 |
| 3. 알림 | 관심 기종·지역 필터, 마감 알림 | 2주간 정상 알림 |
| 4. 연동 | 21번 판매글 흐름·52번 고객 정보 제공 | 연동 완료 |

## 주의
- 현장 확인 없는 참고용 판단, 입찰은 본인이 직접
