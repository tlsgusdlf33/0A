# 82. 펌프 성능곡선 디지털화 & 운전점 판정

> **A6 보완 (2026-11-02 사용자 지시로 'A6. Analysis 보고서' 세션에 전달)**: 73번(해석 보고서)·74번(회전기기 진동)과 같은 펌프 검토 흐름.

## 최종 목표
- 성능곡선 PDF·이미지 → 운전점 판정표까지 10분 이내
- 추출 곡선 오차: 원본 대비 ±2% 이내 (검증 점 기준)

## MVP 범위
- 곡선 추출(유량-양정·효율·NPSHr·동력), 축 눈금 인식 + 사용자 보정
- 시스템 저항곡선(정수두 + 마찰) 입력 → 운전점 계산
- 판정: BEP 대비 운전 범위(%), NPSH 여유(NPSHa/NPSHr), 모터 동력 여유 → 73번 보고서 표로 출력

## 단계별 절차
| 단계 | 할 일 | 완료 기준 |
|---|---|---|
| 0. 샘플 | 실제 성능곡선 3종 수집 | 샘플 확보 |
| 1. 추출 | 축 인식·곡선 디지털화·보정 화면 | 오차 ±2% |
| 2. 운전점 | 시스템 곡선 교차 계산 | 수기 계산과 일치 |
| 3. 판정·출력 | 판정표 → 73번 보고서 첨부 | 보고서 1건 적용 |

## 주의
- 제조사 자료·회사 데이터는 로컬 처리, 판정 책임은 작성자
