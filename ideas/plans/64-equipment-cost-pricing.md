# 64. 장비별 원가 자동 집계 & 적정 대여 단가 산정

> **52번 보완 제안 (2026-10-26)**: 52번(작업확인서·대여료 청구) 앱의 원가 기능으로 추가 권장. 영수증 추출은 18번(G2) 문서 추출 엔진 재사용. 건설기계 묶음(G8) 후보. **작업 대기 (사용량 절약)**

## 최종 목표
- 장비별 시간당 원가(유류·소모품·정비·보험·감가) 자동 산출, 실제 장부 대비 오차 5% 이내
- 적자 현장 0건: 견적이 최소 단가 미만이면 경고

## MVP 범위
- 입력: 52번 작업 기록, 주유·정비 영수증 사진, 고정비(보험·할부·검사)
- 출력: 장비별 월 원가·시간당 원가, 현장별 손익, 최소 대여 단가

## 단계별 절차
| 단계 | 할 일 | 완료 기준 |
|---|---|---|
| 0. 원가 항목 | 장비 사업자 원가 구조 정리 | 항목표 확정 |
| 1. 영수증 추출 | 주유·정비 영수증 → 금액·날짜·장비 | 추출 정확도 95% |
| 2. 원가 계산 | 작업 시간 대비 배분, 감가 반영 | 한 달치 장부와 오차 5% 이내 |
| 3. 현장 손익·경고 | 현장별 손익, 견적 시 최소 단가 경고 | 경고 정상 작동 |

## 주의
- 원가·단가는 참고용, 세무 신고 자료는 28번 장부와 별도 확인
