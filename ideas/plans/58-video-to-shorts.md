# 58. 내 긴 영상 → 쇼츠·릴스 자동 편집 (하이라이트·한글 자막·세로 변환)

> **A21·A2 보완 제안 (2026-10-24)**: 사용자 개인 세션 A21(음원·영상 제작 수익화)의 영상을 입력으로, A2(티스토리·유튜브·틱톡 자동 발행)의 발행 대기열을 출력으로 씁니다. A21 레포에 `shorts/` 모듈로 두고 A2와는 파일·대기열로만 연결하는 것을 권장합니다. 개인 세션이라 사용자가 지시할 때만 전달합니다.

## 최종 목표
- 긴 영상 1편을 넣으면 **10분 안에** 세로 쇼츠 후보 3개(30~60초, 한글 자막 포함) 완성
- 사람이 들이는 시간: 후보 확인·선택 2분 (자막 수정이 필요한 비율 20% 이하)
- 영상 1편당 쇼츠 2개 이상 발행 → A2 채널 발행량 2배, 쇼츠 경유 본편 조회 증가
- 플랫폼 정책 위반(재사용·반복 콘텐츠 경고) 0건

## MVP 범위
- 입력: A21에서 만든 본인 영상(가로 16:9), 선택적으로 음원·대본
- 자막: 음성 인식 → 한글 자막(문장 단위 분할, 맞춤법 보정), 노래 영상은 가사 파일이 있으면 가사 우선
- 하이라이트 후보: 말의 밀도·음량 변화·장면 전환·키워드(대본 강조 구간) 점수 → 30~60초 구간 3개, 앞뒤 자연스러운 끊김 보정
- 세로 변환: 9:16 리프레이밍(얼굴·움직임 중심 추적), 상단 제목·하단 자막 레이아웃
- 출력: MP4(쇼츠·릴스·틱톡 규격), 제목·설명 초안, 본편 링크
- A2 연동: 사용자가 고른 후보만 A2 발행 대기열 폴더/큐로 전달 (발행은 A2 기존 흐름)

## 기술 구조
- 처리: Python + FFmpeg(자르기·크롭·자막 입히기), 음성 인식 모델(로컬 Whisper 계열 또는 API)
- 얼굴·움직임 추적: 경량 비전 모델로 프레임 샘플링 → 크롭 중심 경로 평활화
- 실행: PC에서 처리(무거운 작업), 폰 앱/알림으로 후보 미리보기·선택 (사용자 선호: 폰 중심 + PC 연동)
- 저장: 원본·후보·선택 이력, 같은 구간 중복 사용 방지 기록

## 단계별 절차
| 단계 | 할 일 | 완료 기준 |
|---|---|---|
| 0. 입력 확인 | A21 영상 형식·길이·음원 구성, A2 발행 대기열 형식 확인 | 연결 방식 확정 |
| 1. 자막 | 음성 인식 → 한글 자막, 문장 분할·보정 | 자막 수정 필요 비율 20% 이하 |
| 2. 하이라이트 | 구간 점수 → 후보 3개, 끊김 보정 | 3개 중 1개 이상 바로 쓸 만하다고 판단 |
| 3. 세로 변환 | 9:16 리프레이밍, 자막·제목 레이아웃 | 주요 인물·피사체가 화면 밖으로 나가지 않음 |
| 4. 선택 화면 | 폰에서 후보 미리보기·선택·자막 간단 수정 | 선택 2분 이내 |
| 5. A2 연동 | 선택 후보 → A2 대기열, 제목·설명 초안 | A2에서 정상 발행 |
| 6. 운영 | 2주간 영상 4편 처리, 조회 지표 비교 | 쇼츠 경유 본편 유입 확인 |

## 법·정책 주의사항
- **본인이 권리를 가진 원본만** 사용 (타인 영상·음원 사용 금지)
- 같은 영상을 조금씩 바꿔 반복 업로드하지 않음 (플랫폼의 반복·재사용 콘텐츠 정책 준수), 구간 중복 사용 방지
- AI 생성 음원·영상이 포함되면 각 플랫폼의 AI 콘텐츠 표시 정책에 맞게 표기

## 리스크와 대응
- 음악 위주 영상은 하이라이트 판단이 어려움 → 음원 구조(후렴 구간) 분석 옵션
- 세로 크롭이 어색함 → 인물 없는 영상은 블러 배경 + 가운데 원본 배치 방식 선택
- 처리 시간 → PC 야간 일괄 처리, 아침에 폰으로 후보 확인
