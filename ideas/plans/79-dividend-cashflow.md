# 79. 배당 일정·세후 배당 현금흐름 예측 & 재투자 배분

> **병합 (2026-11-01 사용자 지시)**: '자동 매매 프로그램' 세션(G3 주, 레포 autotrader)에 모듈로 전달. 33번 DART 수집기, 25번 리밸런싱, 36번 세금 규칙 재사용.

## 최종 목표
- 보유 종목 배당 일정·금액을 월별 캘린더로 자동 예측 (실제 입금 대비 오차 5% 이내)
- 금융소득 종합과세 기준 근접 시 경고, 배당 입금 시 재투자 제안(승인 후 주문)

## MVP 범위
- DART 배당 공시·과거 배당 이력 → 예상 배당 캘린더, 세후 금액
- 연간 금융소득 누적 vs 종합과세 기준 경고
- 입금 감지 → 리밸런싱 목표 비중대로 재투자 제안

## 단계별 절차
| 단계 | 할 일 | 완료 기준 |
|---|---|---|
| 0. 데이터 | 배당 공시·이력 수집 (33번 수집기) | 보유 종목 이력 확보 |
| 1. 캘린더 | 월별 예상 배당·세후 금액 | 실제 입금 대비 오차 5% |
| 2. 과세 경고 | 금융소득 누적·기준 근접 알림 | 테스트 알림 정상 |
| 3. 재투자 | 입금 → 재투자 제안 → 승인 주문 | 1회 실행 |

## 주의
- 세법 수치는 설정 파일 분리, 주문은 사용자 승인 후에만
