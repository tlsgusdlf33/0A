# 61. 한국 공공데이터 MCP 서버 패키지 (AI 에이전트용 도구)

> **16번(G7) 보완 제안 (2026-10-25)**: 16번 데이터 API와 31번 공공 API 클라이언트를 AI 에이전트용 MCP 서버로 포장. G7(주 31번)에서 개발하는 것을 권장. **작업 대기 (2026-10-25 사용자 지시: 주간 사용량 절약, 계획만 보관)**

## 최종 목표
- 6개월 안에 MCP 도구 10종 공개, 월 활성 사용자 100명, 유료 API 키 20개
- 16번 API와 같은 코드로 동작 (추가 유지보수 최소)

## MVP 범위
- 도구: 영업일 계산, 공휴일 조회, 사업자번호 검증, 주소 로마자 변환, (이용 조건 확인 후) 실거래가·공시 조회
- 무료 일일 한도 + API 키 종량 과금, MCP 레지스트리·오픈소스 저장소 배포

## 단계별 절차
| 단계 | 할 일 | 완료 기준 |
|---|---|---|
| 0. 이용 조건 | API별 재배포·상업 이용 가능 여부 확인 | 공개 가능 도구 목록 |
| 1. 첫 도구 | 영업일 계산 MCP 서버 | Claude에서 호출 성공 |
| 2. 도구 확장 | 16번 API 3종 + 공공 API 2종 | 도구 5종 |
| 3. 과금 | API 키 발급·한도·사용량 집계 | 유료 키 첫 발급 |
| 4. 배포 | 레지스트리 등록, 사용 예제 문서 | 외부 사용자 50명 |
