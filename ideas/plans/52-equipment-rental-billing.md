# 52. 건설기계 1인 사업자 작업확인서·대여료 청구·미수금 관리 앱

> **연결 제안 (2026-10-22)**: 46번(작업계획서)·51번(진동 진단)과 고객(장비 소유자·임대업체)이 같아 "건설기계 실무 도구" 묶음(가칭 G8)으로 함께 판매할 수 있습니다. 46·51과 장비 정보(기종·차량번호·소유자)를 공유합니다. 사용자가 묶음 통합을 지시하기 전까지는 독립 프로젝트로 진행합니다.

## 최종 목표
- 종이 작업확인서 **0장**: 모든 작업 기록을 폰 전자서명으로 대체
- 월말 청구서 작성 시간 **2시간 → 5분** (자동 집계 확인 후 발송)
- 미수금 회수 기간 단축: 미지급 30일 넘는 건을 **빠짐없이 알림**, 내용증명 초안까지 자동
- 12개월 안에 유료 사업자 50명 (월 9,900원 기준 월 약 50만 원)

## MVP 범위
- 작업 기록: 현장(주소·GPS), 장비, 시작·종료 시각(시간제) 또는 일대(일 단위), 작업 내용, 사진
- 작업확인서: 현장 담당자가 기사 폰 화면에 서명 또는 링크로 받은 문자에서 서명 → PDF 자동 보관·전송
- 청구: 거래처별 월 집계(시간·일수·단가·유류비·운반비), 청구서 PDF, 세금계산서 발행용 자료(엑셀) 내보내기
- 지급보증 체크: 거래처·현장별 대여대금 지급보증서 수령 여부 기록·미수령 경고
- 미수금: 청구일 기준 D+30·60·90 알림, 거래처별 미수 현황, 내용증명·지급명령 신청 참고용 초안
- 백업: 폰 ↔ PC 동기화, 세무사 전달용 월별 자료

## 기술 구조
- 앱: 안드로이드 APK (Termux 없이, 앱 내 업데이트), 오프라인 기록 후 연결 시 동기화 (현장 통신 불안정 대비)
- 서명: 화면 서명 + 서명 시각·위치·기기 정보 기록, PDF에 해시 첨부
- 서명 요청 링크: 문자/카카오톡 공유용 짧은 링크(웹 페이지에서 서명)
- 저장: 폰 로컬 DB + 클라우드 동기화(사용자 계정), PC 웹 화면에서 청구·집계
- 세금계산서: 직접 발행은 하지 않고 홈택스 일괄 발행 양식(엑셀)으로 내보내기
- 결제: Play 결제(앱 구독), 31번 kit·49번 출시 파이프라인 사용

## 단계별 절차
| 단계 | 할 일 | 완료 기준 |
|---|---|---|
| 0. 현장 조사 | 장비 사업자 3명 인터뷰, 실제 작업확인서·청구서 양식 수집, 지급보증 관행 확인 | 필수 항목·흐름 정리 |
| 1. 작업 기록 | 현장·장비·시간 기록, 오프라인 저장, 사진 | 1건 기록 30초 이내 |
| 2. 전자서명 | 화면 서명 + 링크 서명, 작업확인서 PDF | 현장 담당자 서명 1분 이내 |
| 3. 월 청구 | 거래처별 자동 집계, 청구서 PDF, 홈택스 일괄 발행 양식 | 실제 한 달치 청구와 금액 일치 |
| 4. 미수금·보증 | 미수 현황, D+30·60·90 알림, 지급보증 체크, 내용증명 초안 | 테스트 거래처 3곳 시나리오 통과 |
| 5. PC 연동 | 웹 화면에서 집계·수정·출력, 세무사 전달 자료 | 월 마감 5분 이내 |
| 6. 시범 사용 | 사업자 3명 1개월 실사용 | 종이 확인서 사용 0장 |
| 7. 판매 | 무료(장비 1대·월 10건) → 유료, 건설기계 커뮤니티·협회 안내 | 유료 10명 |
| 8. 확장 | 46번 작업계획서·51번 진단 리포트와 연결, 임대업체용 다중 장비·기사 관리 | 다중 장비 요금제 |

## 필요한 계정·API·비용
- Google Play 개발자 계정(보유), 클라우드 저장소·문자 발송(서명 링크용, 건당 소액)
- 지도·주소 API(현장 주소 검색)

## 법·정책 주의사항
- 전자서명 효력: 서명 시각·위치·서명자 연락처를 함께 보관해 증빙력 확보, 분쟁 시 법률 자문 권장 문구
- 내용증명·지급명령 초안은 참고용이며 법률 대리 아님을 명시
- 거래처 담당자 연락처·서명은 개인정보 → 수집 동의, 보관 기간·삭제 정책
- 세금계산서 발행 책임은 사업자 본인

## 리스크와 대응
- 현장 담당자가 서명 앱 설치를 꺼림 → 설치 없이 기사 폰 화면 서명 또는 웹 링크 서명
- 고령 사용자 비중 → 큰 글씨·버튼 3개 이내 화면, 음성 안내
- 기존 장부 앱과 비교 → 작업확인서 서명·지급보증·미수 관리 같은 건설기계 대여 특화 기능으로 차별화
