# 51. 폰 센서 기반 건설기계 진동·이상 추세 진단

> **연결 제안 (2026-10-19)**: 46번(작업계획서·위험성평가)과 장비 사양 DB를 공유하고, 진단 결과를 46번 일일 점검표에 연동할 수 있습니다. 47번과 함께 "건설기계 실무 도구" 묶음(가칭 G8)으로 묶는 것을 제안합니다. 사용자가 지시하기 전까지는 독립 프로젝트로 진행합니다.

## 최종 목표
- 같은 장비·같은 측정 위치에서 반복 측정값 편차 **10% 이내** (추세 비교가 가능한 재현성)
- 정비 이력이 있는 장비 사례에서 이상 징후를 **정비 2주 전 이상** 먼저 표시
- 12개월 안에 장비 소유자·임대업체 유료 구독 30대(장비 기준), 월 매출 30만 원 이상
- 측정 1회 5분 이하 (폰 거치 → 시동 → 자동 측정·분석)

## MVP 범위
- 측정: 폰을 자석 거치대로 정해진 위치(엔진 블록 근처, 유압펌프 하우징, 선회부)에 고정 → 공회전·정격 회전 각 60초
- 분석: 가속도 3축 → FFT 스펙트럼 → 주요 주파수 대역 에너지·피크 위치, 전체 진동 크기(RMS)
- 기준선: 장비별 첫 3회 측정을 정상 기준으로 저장 → 이후 변화율 추세
- 알림: 대역별 변화율이 기준을 넘으면 "점검 권장" + 의심 부위 후보(엔진 마운트·펌프·베어링 등, 참고용)
- 기록: 장비별 측정·정비 이력, 월간 PDF 리포트 (임대 시 장비 상태 증빙)

## 기술 구조
- 앱: 안드로이드 APK (Termux 없이, 앱 내 업데이트), 센서 샘플링 최대 주기 사용, 측정 중 화면 고정·흔들림 감지
- 분석: 폰에서 FFT(경량 라이브러리), 원시 데이터는 압축해 PC·클라우드로 동기화 (폰 중심 + PC 연동)
- 측정 위치 가이드: 기종별 거치 위치 사진 안내, 위치 태그(같은 위치끼리만 비교)
- 기종 정보: 46번과 공유하는 장비 사양 DB (엔진 정격 회전수 → 회전 주파수 대역 계산)
- PC: 장비 대수별 대시보드, 스펙트럼 비교 그래프
- 결제: 장비 대수 기준 구독 (Play 결제)

## 단계별 절차
| 단계 | 할 일 | 완료 기준 |
|---|---|---|
| 0. 센서 성능 확인 | 보유 폰 2~3종의 가속도 센서 최대 샘플링 주파수·잡음 측정 | 분석 가능한 주파수 범위 확정 |
| 1. 측정 앱 | 거치 확인 → 60초 측정 → 원시 데이터 저장 | 측정 1회 5분 이내 |
| 2. 재현성 시험 | 장비 1대, 같은 위치 1주일 반복 측정 | 편차 10% 이내 (못 미치면 거치 방식 개선) |
| 3. 분석 | FFT·대역 에너지·RMS, 회전 주파수 기준 대역 자동 설정 | 스펙트럼 그래프·지표 출력 |
| 4. 기준선·추세 | 첫 3회 기준선, 변화율 추세, 점검 권장 규칙 | 의도적 변화(부하 변경)를 감지 |
| 5. 리포트 | 장비별 월간 PDF, 정비 이력 입력 | 임대 계약 시 첨부 가능한 형식 |
| 6. 현장 시범 | 직장·지인 장비 5대 3개월 측정, 실제 정비 기록과 비교 | 사례 정리 |
| 7. 판매 | 장비 1대 무료 → 대수별 구독, 임대업체 대상 | 유료 장비 10대 |
| 8. 연동 | 46번 일일 점검표에 최근 진단 결과 표시 | 연동 완료 |

## 법·정책 주의사항
- 진단은 참고용이며 정비·안전 판단을 대체하지 않음 → 앱·리포트에 명시
- 측정 중 장비 가동 시 안전 수칙(거치·회수는 장비 정지 상태에서) 안내
- 장비 위치·가동 데이터는 사용자 동의 하에만 수집

## 리스크와 대응
- 폰 센서 정밀도 한계 → 절대값 진단이 아니라 같은 위치·같은 조건의 추세 비교로 한정
- 거치 위치·방식에 따른 값 변화 → 전용 자석 거치대 권장, 위치 태그·흔들림 감지로 품질 낮은 측정 제외
- 고객 확보 → 임대업체에는 "장비 상태 증빙 리포트"로 가치 제안
