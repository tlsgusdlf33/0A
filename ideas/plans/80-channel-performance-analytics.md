# 80. 발행 채널 성과 자동 분석 & 다음 발행 시간·주제 추천

> **A2 보완 (2026-11-01 사용자 지시로 A2 세션에 전달)**: A2(티스토리·유튜브·틱톡 자동 발행)의 예약 발행에 반영. 58번(쇼츠 자동 편집) 결과물 성과도 함께 분석.

## 최종 목표
- 채널별 성과 지표 주 1회 자동 수집·리포트 (사람 손 0분)
- 추천 반영 후 3개월 내 평균 조회·수익 20% 향상

## MVP 범위
- 공식 분석 API(유튜브 등) 지표 수집, API 없는 채널은 사용자가 내려받은 파일 업로드
- 주제·길이·발행 시간대별 성과 비교 → 다음 주 발행 시간·주제 우선순위 추천 → A2 예약 발행 설정에 반영(사용자 확인 후)

## 단계별 절차
| 단계 | 할 일 | 완료 기준 |
|---|---|---|
| 0. 연결 | 채널별 공식 API 권한, API 없는 채널 파일 형식 확인 | 데이터 소스 확정 |
| 1. 수집 | 주 1회 자동 수집 | 4주 연속 정상 |
| 2. 분석·추천 | 시간대·주제·길이별 비교, 추천 | 주간 리포트 생성 |
| 3. 반영 | A2 예약 발행 시간·순서에 반영 | 사용자 확인 후 적용 |

## 주의
- 공식 API·사용자 데이터만 사용(크롤링 금지), 플랫폼 정책 준수
