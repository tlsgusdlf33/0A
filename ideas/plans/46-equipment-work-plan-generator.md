# 46. 차량계 건설기계 작업계획서·위험성평가 자동 작성 앱

> **연결 제안 (2026-10-19)**: 47번(도면 → 물량·견적, A6 보완)·51번(폰 센서 진동 진단)과 함께 "건설기계 실무 도구" 묶음(가칭 G8)으로 묶을 수 있습니다. 장비 사양 DB(기종·자중·작업반경·인양 능력)를 46·51이 공유합니다. 사용자가 병합·통합을 지시하기 전까지는 독립 프로젝트로 진행합니다.

## 최종 목표
- 작업계획서 1건 작성 시간을 **2시간 → 15분 이하**로 단축 (현장·장비 입력 5분 + 검토 10분)
- 산업안전보건기준규칙 제38조(별표 4) 차량계 건설기계 작업계획서 법정 기재 항목 **누락 0건**
- 12개월 안에 유료 고객(중소 시공사·장비 임대업체) 30곳, 월 매출 60만 원 이상
- 사용자 본인 직장에서 실제 업무에 사용해 실적으로 활용

## MVP 범위
- 기종: 굴삭기, 휠로더, 덤프트럭, 이동식 크레인(차량계 양중), 지게차 5종부터
- 입력: 현장 주소·지형(경사·지반 종류), 장비(제조사·모델 선택 → 사양 자동), 작업 내용(굴착·상차·인양 등), 작업 기간·인원
- 출력: 작업계획서(법정 항목: 사용 장비 종류·성능, 운행 경로, 작업 방법), 위험성평가표(위험 요인·빈도·강도·감소 대책), 일일 작업 전 점검표
- 계산: 작업반경 내 출입 통제 범위, 경사지 전도 위험(장비 자중·무게중심 단순 모델), 지반 지지력 확인 필요 여부, 인양 시 정격하중 대비 사용률
- 파일: PDF·HWPX·엑셀, 현장 사진·배치도 첨부

## 기술 구조
- 앱: 안드로이드 APK (Termux 없이, 앱 내 업데이트), 폰에서 현장 입력·사진, PC에서 출력·서명 (폰 중심 + PC 연동)
- 장비 사양 DB: 제조사 공개 사양서 기반 JSON (기종·모델·자중·버킷 용량·최대 작업반경·정격하중표), 버전 관리·검수 이력
- 규칙 엔진: 법정 기재 항목 체크리스트 + 위험 요인 라이브러리(기종 × 작업 유형) → 해당 항목 자동 선택
- LLM: 작업 설명을 구조화하고 대책 문장 초안 작성 (계산·판정은 규칙 엔진, 문장만 LLM)
- 동기화: 폰 ↔ PC 간 클라우드 저장(사용자 계정), 31번 kit 공통 부품 사용
- 결제: 39번 결제 엔진(웹 관리 화면) 또는 Play 결제

## 단계별 절차
| 단계 | 할 일 | 완료 기준 |
|---|---|---|
| 0. 법정 항목 정리 | 산업안전보건기준규칙 제38조·별표 4, 차량계 건설기계 관련 조항(제196조 이하) 기재 항목·점검 항목 표로 정리, 실제 현장 양식 3종 수집 | 항목 대응표 완성 |
| 1. 장비 사양 DB | 5개 기종 × 대표 모델 각 5개 사양 입력, 출처 기록 | 25개 모델 사양 검수 완료 |
| 2. 위험 요인 라이브러리 | 기종 × 작업 유형별 위험 요인·대책 문장 (전도·협착·충돌·낙하·감전) | 라이브러리 100개 항목 |
| 3. 계산 모듈 | 출입 통제 반경, 경사 전도 판정(단순 모델), 인양 사용률, "지반 확인 필요" 조건 | 손 계산 사례 10건과 일치 |
| 4. 문서 생성 | 작업계획서·위험성평가표·점검표 PDF·HWPX·엑셀 출력 | 실제 현장 양식과 항목 일치 |
| 5. 앱 화면 | 폰 입력(장비 선택 → 작업 선택 → 사진), PC 출력, 서명란 | 신규 작성 15분 이내 |
| 6. 본인 실무 검증 | 직장 현장 3건에 시범 적용, 안전관리자 검토 의견 반영 | 수정 요청 반영 완료 |
| 7. 판매 | 무료 월 3건 → 유료(무제한·회사 로고·이력 관리), 건설기계 임대업체·전문건설업체 대상 안내 | 유료 고객 10곳 |
| 8. 확장 | 기종 확대(항타기·고소작업대 등), 51번 진동 진단 결과를 점검표에 연동 | 기종 10종 |

## 필요한 계정·API·비용
- Google Play 개발자 계정(보유), 클라우드 저장소, LLM API(문장 초안만, 건당 수 원)
- 장비 사양서: 제조사 공개 자료 사용, 출처 표기

## 법·정책 주의사항
- 작업계획서 작성·확인 책임은 사업주·작성자에게 있음 → "초안 작성 도구"임을 문서와 앱에 명시, 계산은 보수적으로
- 제조사 사양서 저작권: 수치(사실 정보)만 사용, 문서·도면 원본 재배포 금지
- 회사 업무에 쓸 경우 회사 내부 양식·보안 규정 확인, 현장 사진의 개인정보(작업자 얼굴) 처리 주의

## 리스크와 대응
- 계산 단순화로 인한 오판 → 판정 결과는 "확인 필요"로 보수적 표시, 근거 수치 함께 출력
- 현장마다 양식이 다름 → 양식 템플릿 커스터마이즈 기능(로고·항목 순서)
- 사양 DB 유지 부담 → 많이 쓰는 모델부터, 사용자 요청 모델 추가 방식
