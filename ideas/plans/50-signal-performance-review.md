# 50. 매매 신호 성과 자동 검증 & 신호 품질 리포트

> **자동 매매 프로그램(G3 주) 보완 제안 (2026-10-19)**: 사용자 개인 세션 '자동 매매 프로그램'(레포 autotrader, G3 투자 비서 주 세션)의 매매신호앱에 붙는 기능입니다. 그 세션이 이미 25·33·36·19번을 모듈로 통합 중이므로 같은 구조의 모듈로 추가하는 것을 권장합니다. 사용자가 병합을 지시하면 자동 매매 세션으로 전달합니다.

## 최종 목표
- 매매신호앱이 낸 **모든 신호의 사후 성과를 100% 자동 기록** (누락 0건)
- 신호 규칙별 승률·평균 수익률·최대낙폭을 매주 자동 산출, 성과가 기준 아래로 떨어진 규칙을 **2주 안에 감지**
- 6개월 데이터로 성과가 나쁜 규칙을 정리해 전체 신호의 기대 수익(수수료·세금 차감 후)을 개선
- 사용자 확인 시간: 주 10분 (주간 리포트)

## MVP 범위
- 신호 기록: 시각, 종목, 방향(매수·매도), 신호 규칙 이름·파라미터, 당시 가격, 시장 지수
- 사후 평가: 1·5·20거래일 수익률, 목표가·손절가 도달 여부, 최대 역행 폭, 수수료·세금 반영
- 집계: 규칙별·종목군별·시장 국면별(지수 추세 기준 상승·하락·횡보) 성과표
- 경고: 최근 N건 성과가 장기 평균보다 통계적으로 유의하게 나쁠 때 알림
- 실제 체결 비교: 자동 매매 프로그램의 실제 체결과 신호가의 차이(슬리피지)
- 연결: 33번 공시 위험이 있었던 신호, 36번 양도세 영향을 성과표에 함께 표시

## 기술 구조
- 자동 매매 레포 안의 모듈: 신호 발생 지점에 기록 훅 추가 → 로컬 DB(SQLite)
- 시세: 이미 쓰고 있는 증권사 API·시세 소스 재사용 (추가 키 없음)
- 평가 작업: 장 마감 후 하루 1회 배치
- 리포트: 매매신호앱 안 "신호 성적표" 화면 + 주간 요약 알림, PC에서 상세 표(엑셀 내보내기)
- 통계: 이동 승률, 부트스트랩 신뢰구간으로 "우연인지" 판단

## 단계별 절차
| 단계 | 할 일 | 완료 기준 |
|---|---|---|
| 0. 신호 구조 파악 | 자동 매매 레포의 신호 생성 위치·규칙 목록·로그 확인 | 기록할 필드 확정 |
| 1. 기록 훅 | 모든 신호를 DB에 기록 (과거 로그가 있으면 백필) | 1주일간 신호 누락 0건 |
| 2. 사후 평가 | 1·5·20일 수익률, 목표·손절 도달, 비용 반영 | 손 계산 10건과 일치 |
| 3. 집계·국면 | 규칙별·국면별 성과표 | 주간 성과표 자동 생성 |
| 4. 경고 | 성과 악화 감지 규칙, 오탐 조정 | 과거 데이터로 시험 시 의미 있는 경고만 발생 |
| 5. 앱 화면 | 신호 성적표 화면, 주간 알림 | 앱에서 확인 가능 |
| 6. 개선 루프 | 성과 나쁜 규칙 파라미터 재검토 제안 → 사용자 승인 후 변경, 변경 전후 비교 | 첫 개선 사이클 완료 |

## 법·정책 주의사항
- 본인 판단용으로 운영. 앱 사용자에게 성과를 공개하거나 신호를 유료 제공하면 **유사투자자문업 신고** 등 규제 대상이 될 수 있음 → 공개 전 반드시 확인
- 과거 성과는 미래 수익을 보장하지 않는다는 표시
- 자동 매매 규칙 변경은 사람 승인 후에만

## 리스크와 대응
- 표본이 적어 결론이 불안정 → 신뢰구간 표시, 최소 표본 수 미만이면 판단 보류
- 과최적화(성과 좋은 구간에만 맞춘 파라미터) → 변경 후 일정 기간 별도 검증 구간 운영
- 시세 데이터 누락 → 평가 실패 건은 재시도·누락 리포트
