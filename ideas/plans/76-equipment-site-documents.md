# 76. 장비 현장 반입 서류 자동 묶음 & 만료 점검

> **52번 보완 제안 (2026-10-31)**: 52번(작업확인서·대여료 청구) 앱에 서류함 기능으로 추가 권장. 서류 사진 추출은 18번(G2) 엔진 재사용. 건설기계 묶음(G8) 후보. **작업 대기 (사용량 절약)**

## 최종 목표
- 현장 반입 요청 시 필요 서류 묶음 공유까지 1분 이내
- 만료된 서류로 반입 거부 0건 (만료 30·7일 전 알림)

## MVP 범위
- 서류 종류: 건설기계 등록증, 보험증권, 정기검사증, 조종사 면허, 안전점검표(+현장별 추가 서류)
- 사진 등록 → 만료일·번호 추출 → 만료 알림
- 현장별 요구 서류 체크리스트 → PDF 한 묶음 → 문자·카톡 공유 링크(기간 제한)

## 단계별 절차
| 단계 | 할 일 | 완료 기준 |
|---|---|---|
| 0. 서류 목록 | 현장 반입 시 요구 서류 조사 (현장 3곳) | 기본 체크리스트 |
| 1. 등록·추출 | 사진 → 만료일·번호 추출 | 추출 정확도 95% |
| 2. 만료 알림 | 30·7일 전 알림 | 테스트 알림 정상 |
| 3. 묶음 공유 | 체크리스트 → PDF → 기간 제한 링크 | 1분 이내 공유 |

## 주의
- 면허·등록증은 개인정보 → 기기 암호화 저장, 공유 링크는 기간 만료 후 자동 삭제
